# v0.01 判定与角色入口

数值权威为《数值定稿v1.0.md》，本文件不再保留旧十点生命规则。

- 2d6 + 属性 + 最多一个标签 + 有限处境/协助 + 难度，总修正上限 +5。裸骰 2 为大失败，12 为大成功；其他结果合计 ≤6 失败、7–9 代价成功、≥10 成功。
- 六属性：体魄、灵巧、心智、感知、交涉、意志。均衡 +2/+1/+1/0/0/−1；专精 +2/+2/0/0/0/−1；通才 +1/+1/+1/+1/0/−1。三方案均 +3。
- 基础 HP=120+体魄×15；减伤=体魄×5，可为负；能量起始/上限 3，装备派生值由引擎计算。
- 战斗各自行动，剧情一次检定代表共同任务。具体行动、敌怪、装备与恢复均调用持久化工具，不自填结果。
- 单人玩家+旅行者，其他 NPC 只作有限支援；多人为3–4玩家，无旅行者常规战斗位。
