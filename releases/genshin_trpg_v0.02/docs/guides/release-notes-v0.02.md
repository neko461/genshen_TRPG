# genshin_trpg v0.02 版本说明

更新日期：2026-10-28。包版本0.0.2，产品标识genshin_trpg_v0.02。本次在原2026-10-18的v0.02基础上整合当前工作区改动，发布到https://github.com/neko461/genshin_trpg。npm注册表发布与GitHub源码/ZIP发布是两个流程，本次不执行npm publish。

## 新增内容

- 角色库：8地区192条角色JSON，正文text、稳定id、别名搜索和单人读取，GM后台/玩家可见知识分开，保持阶段和禁止级约束。
- 主持：分层opening、短核心契约、当前地区与固定章节索引；mainline查询覆盖完整节奏和调查要求，自由输入、行动边界、自然对话和公开裁定继续执行。
- 建卡：GM主动拟定可玩能力、按事实拟定两项优势和一项局限，可选跨界来客并压制外来力量；初始武器品质与特效门槛清楚区分。
- 地区与主线：势力/人物/钩子分离，角色出场机会、世界因果、调查深度、旅行者关键行动与玩家参与得到补充；不把外围琐事或快速梗概当完成整章。
- 战斗：按实际参战者限制独行普通遭遇，保留单首领例外；完善敌方反应、撤退代价和装备生命加值，统一真实套装计算与说明。
- 保存：主动保存、进度说明、恢复为新聊天/存档分支，保留来源；负标签、事实纠正、线程分类/换站门槛、日期和同行状态一致性改进。
- 上下文：紧凑JSON、精确状态增量/current，完整load及重放恢复；规则分主题、资料按阶段、有界Journal缓存、usage数字统计及可复现字符量诊断。
- 命名与组织：GitHub与DSH/npm身份统一genshin_trpg；文档英文目录分类；旧槽位记忆键兼容，真实源码目录code/dsh-trpg保留。
