## W-4　茜特菈莉与古名持有者的一致性问题 ⚠️

**裁定原文**：「纳塔的角色**茜特菈莉**注意与世界观设定中古名持有者保持一致性。」

我核对后发现**三处不一致**，其中茜特菈莉只是其中之一。

### W-4-A　古名持有者名单比对

| 来源 | 名单 |
|---|---|
| `world_setting.md`（古名条目） | 玛薇卡—基扬戈兹（领袖）、玛拉妮—沃摩延（团结）、基尼奇—马力卜（回火）、希诺宁—巴莱卡（祝福）、恰斯卡—武卡（超越）、欧洛伦—庇迪（奉献）、伊安珊—力量、卡齐娜—乌沙博蒂（坚强）、特拉佐莉—翁杜古（亲情） |
| `nata.md` 各角色条目实际标注的古名 | 卡齐娜—乌沙博蒂 ✅、希诺宁—巴莱卡 ✅、欧洛伦—庇迪 ✅、伊安珊—力量 ✅ |
| `nata.md` **未标注古名**的 | **玛薇卡**、**玛拉妮**、**基尼奇**、**恰斯卡**、**茜特菈莉**、瓦雷莎 |
| `world_setting.md` **列出了但 `nata.md` 无对应角色** | **特拉佐莉**—翁杜古（亲情） |

**问题**：

1. **茜特菈莉**：`nata.md` 称她为「烟谜主（米克特兰）的传奇萨满」「掌握着纳塔最古老的萨满知识」，【秘密(GM)】写「她对『古名』的理解可能触及夜神之国的底层规则」——但**她自己有没有古名，文档完全没说**。`world_setting.md` 的古名名单里也**没有她**。
2. **玛薇卡**：`world_setting.md` 给她的古名是「**基扬戈兹**（领袖）」，但 `nata.md` 的玛薇卡条目**通篇未提古名**。她是火神，古名归属需明确。
3. **特拉佐莉**：`world_setting.md` 有「特拉佐莉—翁杜古（亲情）」，但 `nata.md` **没有这个角色的条目**。（`nata.md` 的纳塔角色有玛薇卡、基尼奇、卡齐娜、玛拉妮、希诺宁、恰斯卡、欧洛伦、茜特菈莉、伊安珊、瓦雷莎、阿瓜拉、咔库库 + NPC 伊法、阿伊祖、杜塔、图娜卡、穆奇赫、卡拉穆鲁、凯瑟琳。**无特拉佐莉**。）

### W-4-B　`nata.md` 内部对「六英雄」的界定不统一

| 位置 | 表述 |
|---|---|
| 地区定位 | 「六英雄**已觉醒**并击退深渊入侵」 |
| 世界书条目 | 「**六英雄**为：希诺宁（回声之子）、基尼奇（悬木人）、玛拉妮（流泉之众）、欧洛伦（烟谜主）、恰斯卡（花羽会）、伊安珊（沃陆之邦）」 |
| 各角色条目 | `nata.md` 中标注「**六英雄之一**」的有：**基尼奇、卡齐娜、玛拉妮、希诺宁、恰斯卡、欧洛伦、伊安珊** —— **共 7 人** |
| 矛盾点 | 世界书列 6 人（**不含卡齐娜**）；角色条目标了 7 人（**含卡齐娜**） |
| 茜特菈莉 | 标注为「烟谜主部族的精神领袖」，**未标六英雄** |
| 玛薇卡 | 标注为「火之神，纳塔领袖」，**未标六英雄** |

**所以「六英雄」到底是谁？** 世界书 6 人与角色条目 7 人冲突，且卡齐娜在两处结论相反。
