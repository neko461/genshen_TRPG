## Z-1　哥伦比娅与霜月之子：伤痕过往 ✅（解决 Y-7-3）

**裁定：不是「神归故里」的温馨重逢，而是一段复杂且充满伤痕的过往。**

### 三段结构

| 阶段 | 内容 |
|---|---|
| **① 曾被奉为「许愿机」** | 哥伦比娅诞生后，被霜月之子**尊为预言中的新神**。但族人在漫长苦难中，**只将她视为「万能的许愿机」，无休止地索取，而非出于爱与信仰**。 |
| **② 因失望而离去** | 在**无法回应所有愿望而招致怀疑和贪婪**后，哥伦比娅意识到**这里并非她的「家」**，最终**选择离开，并加入了愚人众**。 |
| **③ 归属感的缺失** | 即便在「空月之歌」剧情后她**接纳了霜月之子，将挪德卡莱视为「真正的家」**，她**最初对霜月之子也缺乏归属感**。 |

### 因此 `nuodekalai.md` 三处待改文本的最终处理

| 位置 | 现文本 | 改为 |
|---|---|---|
| 菈乌玛条目 | 「**霜月女神消失之后**，菈乌玛带领族人坚守信仰」 | 保留「消失」的结构，但需明确：**她的离开不是陨落，而是失望后的离去**。菈乌玛的「坚守」因此带有**代族人赎罪**的意味 |
| 菈乌玛条目 | 「这个群体信仰一位**他们从未亲眼见过**的神明」 | **可以保留**——但含义变了：不是「神从未降临」，而是**神曾降临、又被族人的贪婪逼走**。族人「从未见过」的是**归来后的她** |
| 霜月女神条目 | 「霜月之子信仰一位**他们从未亲眼见过**的神明……与库塔尔之间的关系尚不明确」 | 「关系尚不明确」→ **改为明确**：霜月之子信仰的**正是哥伦比娅（库塔尔）**。「从未亲眼见过」的含义同上 |

### 菈乌玛的定位随之深化

她**知道**这段历史（她是咏月使、连接神与人的桥梁），因此她的处境是：

```
族人：仍在向神索取（或已因神离去而信仰动摇）
    ↑
菈乌玛：夹在中间——既理解族人的苦难，也理解神为何离去
    ↓
至冬势力：趁信仰裂痕渗透
```

**这正好接上 `nuodekalai.md` 现有的菈乌玛秘密**：「因信仰月神的信徒被至冬势力渗透威胁，她被迫承担对抗至冬势力的使命」——**渗透之所以可能，正是因为信仰本身已经裂了**。

**建议新增的秘密(GM)**：菈乌玛是**唯一知道哥伦比娅为何离开的人**（或至少是知道得最多的），而她**不能对族人说出真相**——因为真相会让族人明白，是他们自己把神逼走的。

## Z-2　风花节 ✅（新增设定）

### 定位

蒙德**最重要的传统节日之一**，重要性「**不下于海灯节对于璃月**」。

### 核心要素

| 项 | 内容 |
|---|---|
| **起源** | 约 **2600 年前**，为**纪念推翻暴君迭卡拉庇安（龙卷之魔神）统治而牺牲的英雄们**所创 |
| **「风之花」的真相** | **并非某种真实的花朵**，而是旧蒙德时期反抗者们用来**秘密联络、共约反抗**的**「暗语」** |
| **核心传统** | 向**风神巴巴托斯**献上自己心中的「风之花」，表达敬意与爱戴；同时这也是属于**自由与爱情**的节日，人们会向**心爱或珍重的人**送花 |
| **主要活动** | **射箭**（纪念开拓历史）、**飞天**（纪念风之翼的诞生）、**弹琴**（与风神持有的**天空之琴**有关） |
| **民众认知** | 如今大多数蒙德人已将风花节视为**恋人的节日**，热恋中的人们会结伴前往**誓言岬**表达爱意 |
| **温迪的参与** | 他会**以吟游诗人身份参与节日**，但**通常不会公开自己的神明身份** |
| **节日核心** | 纪念英雄与追求自由的精神，**而非单纯纪念温迪本人** |

### 设计上最有价值的两个点

**① 「风之花」是暗语，不是花。**
这是整个节日最锋利的一层：**节日的表面是送花示爱，内里是一段「用暗语串联起来的反抗」**。这为「节庆气氛不对」提供了天然的叙事工具——**暗语可以被再次启用**：

- 节日期间出现**不该出现的「风之花」暗语**（旧反抗者的联络方式被人重新使用）。
- 或者：**暗语的原意被遗忘，只剩送花的习俗**——有人刻意唤醒它，是一种危险的信号。

**② 温迪以吟游诗人身份在场。**
回蒙德段他**一定会在场**，而且**不会公开身份**。他可以是：
- 把「气氛不对」第一条线索**以歌谣形式**透露出来的人；
- 玩家调查时**偶尔出现在附近**、说些看似无关的话的人；
- **最终不愿直接出手**（符合他「看起来什么都不做，实际上一直在暗中守护」的设定）。

### 起源年份的一个核对

风花节起源「**约 2600 年前**」，与 `shijie.md` 的「除雷电影和雷电真兄妹同样诞生于**两千多年前**」在数量级上接近但**不是同一事件**（风花节是推翻迭卡拉庇安，雷神姐妹是魔神战争时期）。**两者无冲突**，但如果日后做统一年表，这两个「两千多年」需要各自定位。

## Z-3　回蒙德段的落地设计（结合 W-1 + Y-5 + Z-2）

### 场景骨架

```
玩家与旅行者结束纳塔段，回蒙德过风花节
      ↓
① 气氛不对 —— 节庆的异常
      ↓
② 协助调查 —— 分头收集线索
      ↓
③ 核心发现 —— 深渊教团试图复活魔龙杜林
      ↓
④ 命运抢占 —— 先复活小杜林，抢占命运的轨迹
      ↓
⑤ 希穆兰卡 —— 旅行者一行人完成对小杜林的安抚
      ↓
⑥ 天命既定 —— 改写结局的小杜林成为善龙
      ↓
⑦ 中和 —— 阿贝多借魔龙杜林心脏里的能量，与小杜林中和，创造出杜林
      ↓
⑧ 危机终结 —— 魔龙杜林的危机彻底解决
      ↓
前往挪德卡莱
```

| **温迪** | 以吟游诗人身份在场，不公开身份 |
| **琴** | 法尔伽未归，她仍代理日常事务；节庆安保由骑士团负责 |
| **法尔伽** | **不在蒙德**（仍在挪德卡莱，W-1/V-1 已定） |
