# 武器与圣遗物体系设计 v0.1

> 承接 `stat-system-design.md`。本轮落实：**圣遗物取消随机词条 → 固定数值加成 + 2件套/4件套额外加成**；**五类武器按特点表映射为战斗数值**。
> 本文所有战斗数值都遵守 `stat-system-design.md` §2.2 的**修正天花板**（属性 ≤+3、标签单次仅 1 个、装备 ≤+1、处境 ±1、总计 ≤+5），因此武器/圣遗物**不能给检定修正**，只能给**战斗域内的独立数值**。

---

## 第一部分：武器体系

### 1.1 设计原则

**你的五类武器特点表**：

| 武器 | 攻速 | 伤害 | 防御 | 受击率 |
|---|---|---|---|---|
| 单手剑 | 快 | 中 | 中 | 高 |
| 双手剑 | 慢 | 高 | 高 | 高 |
| 弓 | 快 | 中 | 低 | 低 |
| 法器 | （元素反应加成） | 低 | 低 | 低 |
| 长枪 | 中 | 中 | 中 | 中 |

**转译规则**（把四个模糊词变成可计算的量）：

| 特点 | 转译为 | 机制落点 |
|---|---|---|
| **攻速** | **先攻修正** | 战斗第一轮的行动顺序；也用于「抢在对方之前」的对抗 |
| **伤害** | **伤害档位** | 命中后造成的点数 |
| **防御** | **伤害减免** | 每次受击减去的点数 |
| **受击率** | **仇恨权重** | 敌人选择目标时的权重（明确的仇恨机制） |
| **元素反应加成** | **法器专属特效** | 见 §1.3 |

**关键决策**：**武器不给检定修正**。理由——武器若给 +1，就会和标签、属性、圣遗物叠在一起，直接触到 +5 天花板。所以武器的价值全部放在**战斗域**，与检定域解耦。这也让「换武器」有意义（改变战斗表现），但不会让「换武器」变成「换骰运」。

### 1.2 五类武器数值表

| 武器 | 伤害 | 伤害减免 | 先攻修正 | 仇恨权重 | 一句话定位 |
|---|---|---|---|---|---|
| **单手剑** | 1–2 | 0 | **+1** | **1.5** | 万金油，攻守平衡，但容易被打 |
| **双手剑** | **2–3** | **−1** | 0 | **1.5** | 最硬的输出，最慢的出手 |
| **弓** | 1–2 | +1（更易受伤） | **+2** | **0.5** | 先手输出，脆，但很少被选中 |
| **法器** | **1** | +1（更易受伤） | **+2** | **0.5** | 伤害最低，但元素反应最强 |
| **长枪** | 1–2 | 0 | +1 | **1.0** | 完全居中，无短板也无长处 |

数值说明：

- **伤害减免**列：`−1` = 每次受击少受 1 点；`0` = 无修正；`+1` = 每次受击**多受 1 点**（防御低）。
- **仇恨权重**：多个我方单位在场时，敌人按权重随机选目标。权重 **1.0 是基准**。因此单手剑/双手剑（1.5）会**明显更常被打**，弓/法器（0.5）**明显更少被打**——这直接实现了你的「受击率高/低」。
- **先攻修正**：用于第一轮排序；相同时用**感知**属性作决胜。

### 1.3 各武器的专属特效（★★★ 以上解锁）

武器的特效是「让这把武器有意思」的地方，每把只给**一个**效果，避免堆叠。

**单手剑**
> **连击**：若本轮攻击的检定结果为「大成功」，可立即追加一次伤害减半的攻击（1 点）。
> ——呼应「攻速快」。

**双手剑**
> **破防**：命中后，目标本场战斗的伤害减免 −1（可叠加至 −2）。
> ——呼应「伤害高、防御高」：它自己硬，还能把别人变脆。

**弓**
> **先手狙击**：战斗第一轮的攻击若命中，伤害 +1。
> ——呼应「受击率低、攻速快」：抢在第一轮打出价值。

**法器**
> **元素亲和**：触发的元素反应**加成翻倍**（如蒸发从 +2 变 +4）；且每场战斗一次，可**无视目标的元素附着状态**直接触发一种反应。
> ——呼应「元素反应加成」，也是它伤害低（仅 1 点）的补偿。

**长枪**
> **拒马**：本轮若未移动，受到的伤害 −1；且敌人无法在近身时获得先攻优势。
> ——呼应「攻速中、防御中、受击率中」：站桩型，靠稳住阵线吃饭。

### 1.4 是否削减武器数量

**我的建议：保留五类，不要削减。**

理由：
1. 你的特点表已经让五类**互不重复**（单手剑 vs 长枪都是「中中中」但先攻不同；弓 vs 法器都是脆皮远程但输出方式不同）。
2. 五类对应你九份文档里角色的 `【元素/武器】` 字段——现有角色用满了五类（香菱长枪、行秋单手剑、北斗双手剑、安柏弓、凝光法器）。**削减会导致现有角色卡无武器可用**。
3. 桌上跑团的分支不需要「更多」，但需要「有区别的少数」。五类正好。

**如果你仍想削减**，我建议的优先顺序是：
- 先合并**单手剑 + 长枪**（两者都是「中伤害、无减伤」，差异只在先攻 +1 与拒马特效）→ 减为四类。
- **不建议动法器**——它是唯一的元素反应专精，删掉会让 `elemental_reaction.md` 的 11 条反应失去主要使用者。
- **不建议动双手剑**——它是唯一的减伤武器，删掉就没有「坦克」定位。

## 第二部分：圣遗物体系

### 2.1 结构：4 槽位 + 2件套 / 4件套

**槽位定名**（借用原神的语汇，便于玩家理解）：

| 槽位 | 名称 | 主加成 | 说明 |
|---|---|---|---|
| 1 | **生之花** | 固定：**HP +1** | 生存 |
| 2 | **死之羽** | 固定：**先攻 +1** | 机动 |
| 3 | **时之沙** | 固定：**由套装决定** | 核心，随套装变化 |
| 4 | **空之杯** | 固定：**由套装决定** | 核心，随套装变化 |

**槽位数为什么是 4 而不是 3 或 5**：
- **3 个槽位无法构成 4 件套**，所以你要求的「2件套/4件套」需要**至少 4 个**。
- **5 个槽位**（原神本体）在桌上跑团里管理成本偏高（每次换装要动 5 项）。
- **4 个**是最小可行值：既能凑满 4 件套，也能做「2+2」的混搭，且玩家一眼能记住。

**套装生效规则**：
- 装备 **2 件**同一套装 → **2件套效果**
- 装备 **4 件**同一套装 → **2件套效果 + 4件套效果**（叠加，不是替换）
- 混搭 **2+2** → 两个套装的 2件套效果

**修正天花板的一致性**：所有圣遗物数值**只作用于战斗域与 HP**，**不给检定修正**。这样无论如何搭配，都不会把检定推到 +5 上限。

### 2.2 逐槽位的固定加成（不随机）

| 槽位 | 固定加成 |
|---|---|
| 生之花 | **HP +1** |
| 死之羽 | **先攻 +1** |
| 时之沙 | 由套装决定（见 §2.3） |
| 空之杯 | 由套装决定（见 §2.3） |

**「固定」的含义**：任何一件★相同、槽位相同的圣遗物，其基础加成**完全相同**。差异只来自**品质（★）**与**套装**。

**品质缩放**：

| 品质 | 单件基础加成 | 2件套效果 | 4件套效果 |
|---|---|---|---|
| ★ 凡品 | 无加成（仅占位） | 无 | 无 |
| ★★ 良品 | 基础值 | 无 | 无 |
| ★★★ 精品 | 基础值 | ✅ 生效 | 无 |
| ★★★★ 秘宝 | 基础值 ×1 | ✅ 生效 | ✅ 生效 |
| ★★★★★ 神铸 | 基础值 ×1 + 1 项独特效果 | ✅ 生效 | ✅ 生效 + 强化 |

即：**2件套效果从 ★★★ 起生效，4件套效果从 ★★★★ 起生效**。这给了品质阶梯明确的功能意义——★★★ 让圣遗物「开始有用」，★★★★ 才让「套装有意义」。

### 2.3 套装效果示例（6 套，可按地区扩充）

每套给出「时之沙/空之杯的固定加成」+「2件套」+「4件套」。

**① 角斗士的终幕礼**（战斗向，通用）
- 时之沙：伤害 +1 ｜ 空之杯：伤害 +1
- **2件套**：伤害 +1
- **4件套**：本轮未移动时，伤害 +1；大成功时额外造成 2 点伤害

**② 追忆之注连**（生存向）
- 时之沙：伤害减免 +1 ｜ 空之杯：伤害减免 +1
- **2件套**：HP +2
- **4件套**：受到的伤害减免至多 2 点（即单次受击上限为 2 点）

**③ 翠绿之影**（元素向）
- 时之沙：元素反应加成 +1 ｜ 空之杯：元素反应加成 +1
- **2件套**：元素反应加成 +1
- **4件套**：每场战斗一次，可无视附着状态直接触发一种反应；反应造成的持续伤害持续 3 轮而非 2 轮

**④ 如雷的盛怒**（先攻/机动向）
- 时之沙：先攻 +1 ｜ 空之杯：先攻 +1
- **2件套**：先攻 +2
- **4件套**：战斗第一轮可行动两次（第二次伤害减半）

**⑤ 悠古的磐岩**（承伤向）
- 时之沙：HP +2 ｜ 空之杯：伤害减免 +1
- **2件套**：仇恨权重 +0.5（更常被敌人选中，配合高防御）
- **4件套**：每场战斗一次，可将对**友方**的一次伤害转移给自己（转移后该伤害 −1）

**⑥ 沉沦之心**（恢复向）
- 时之沙：HP +2 ｜ 空之杯：HP +2
- **2件套**：每场战斗结束时恢复 1 点 HP
- **4件套**：元素能量上限 +1；每场战斗一次，使用元素技不消耗能量

### 2.4 圣遗物与「不可逆代价」

按 `stat-system-design.md` §4.2，★★★★ 以上**不可购买**，只能通过**遗迹**（递进检定链）或**馈赠**（关系门槛）获取。因此：

| 品质 | 获取通道 | 难度 | 代价 |
|---|---|---|---|
| ★ ★★ | 市集购买 | 无需检定 | 摩拉 |
| ★★★ | 委托 / 打造 | 容易～普通 | 摩拉 + 任务 |
| ★★★★ | 遗迹 / 馈赠 | **困难，2–3 次递进检定** | **不可逆**：暴露身份、背上债务、招致势力敌意、失去某个关系 |
| ★★★★★ | **仅剧情 / 神明赐予** | **极难，3–4 次递进检定** | **不可逆 + 剧情级后果** |

**建议**：每次获得 ★★★★ 以上圣遗物时，**必须定义一项不可逆代价**（写入存档的 `flags`）。这让「变强」永远有叙事重量。

## 第三部分：战斗流程（整合后）

### 3.1 一轮的行动顺序

```
① 计算先攻
   先攻值 = 感知属性 + 武器先攻修正 + 圣遗物先攻加成 + 情境（如埋伏 +2）
   降序排列。相同则我方优先（玩家体验更好）

② 每个单位行动一次（4件套「如雷的盛怒」可行动两次）

③ 行动结算
   攻击：检定（2d6 + 属性 + 标签）→ 档位决定是否命中与伤害
     大成功：伤害 +2
     成功：正常伤害
     成功带代价：伤害减半（向上取整）或造成伤害但自己也受伤
     失败：未命中，GM 推进局势
     大失败：未命中且自己陷入不利

   伤害计算：武器伤害骰 → + 元素反应加成 → + 圣遗物伤害加成 → − 目标伤害减免

④ 战斗轮次 +1，检查硬上限（4 轮）→ 到点强制 stalemate
```

### 3.2 仇恨机制（受击率的落地）

我方有多个单位时，敌人选择目标：

```
目标权重 = 武器仇恨权重 + 圣遗物仇恨修正 + 情境修正（如保护某人）
按权重随机选择
```

**示例**：队伍为 双手剑（1.5）+ 弓（0.5）+ 长枪（1.0），总权重 3.0。
- 双手剑被选中概率 = 1.5 / 3.0 = **50%**
- 弓被选中概率 = 0.5 / 3.0 = **16.7%**
- 长枪被选中概率 = 1.0 / 3.0 = **33.3%**

这直观体现了你的「受击率高/低」，且**给了玩家主动坦克的手段**（双手剑凑「悠古的磐岩」2件套可到 2.0 权重 = 57%）。

### 3.3 敌人数值表（补上 `stat-system-design.md` 的 E-4）

| 威胁等级 | 敌人 HP | 单次伤害 | 先攻 | 建议数量 |
|---|---|---|---|---|
| **1 杂兵** | 3 | 1 | 0 | 2–4 个 |
| **2 劲敌** | 6 | 2 | +1 | 1–2 个 |
| **3 首领** | 10 | 3 | +2 | 1 个（可带 1–2 杂兵） |

**核对**：角色 HP = `8 + 体魄修正`（7–10）。
- 面对 1 个 **3 级首领**（3 伤害/轮）：7–10 HP 可撑 **3–4 轮** ✅ 正好卡在硬上限上。
- 面对 2 个 **1 级杂兵**（共 2 伤害/轮）：可撑 4–5 轮 ✅ 有压力但不致命。
- 面对 1 个 **1 级杂兵**（1 伤害/轮）：几乎无威胁 ✅ 适合「走过场」的遭遇。

**这个对齐是本次数值设计的关键**：威胁等级 → HP/伤害 → 角色存活轮数 → 战斗硬上限，四者第一次串成一条线。

## 第四部分：需要你确认的 4 项

| 编号 | 问题 | 我的建议 |
|---|---|---|
| **4-1** | 圣遗物槽位定为 **4 个**（生之花/死之羽/时之沙/空之杯）是否认可？ | **建议 4 个**。3 个凑不出 4 件套；5 个管理成本过高 |
| **4-2** | 品质门槛：**2件套从 ★★★ 起、4件套从 ★★★★ 起** 是否认可？ | **建议认可**。这让品质阶梯有明确功能意义 |
| **4-3** | **法器伤害只有 1 点**（明显低于其他武器）是否是你要的？ | **建议维持 1 点**，但以「元素亲和」特效（反应加成翻倍 + 每场一次无视附着）作为补偿。若你觉得太弱，可提到 1–2 |
| **4-4** | 是否采用**仇恨机制**（受击率的数值化落地）？ | **建议采用**。这是让「受击率高/低」不流于文字的唯一方式，也让队伍站位与坦克定位有意义 |
