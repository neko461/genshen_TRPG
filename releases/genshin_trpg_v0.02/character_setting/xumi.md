【地区定位】草元素的国度，雨林与沙漠并存。教令院是学术管理机构，六大学派中以知论派和因论派最为核心；进入本章时虚空系统仍被用于知识与日常事务，关闭须待对应剧情。
【当前时间线】须弥篇进入阶段：花神诞祭循环、教令院控制与造神冲突尚未解决。纳西妲尚未因本章事件获得公开全面执政，虚空仍在运作；散兵不是已改造的流浪者。神之心交换、切片处置和世界树记忆事件均须在相应阶段后处理。
【阶段阅读规则】正式采用《mainline-rules.md》及《timeline.md》的亲历路线。正文中仍以“已完成/已退位/已恢复/现状”记述的后期人物或危机结局，是到达对应节点后才启用的资料；不得据此跳过主线、提前授予NPC知识或把未来结果当成当前事实。
【关键地点】须弥城、教令院、净善宫、化城郭、道成林、阿如村、赤王陵、缄默之殿、桓那兰那、奥摩斯港。
【主要势力】教令院（六大学派）、三十人团、镀金旅团、缄默之殿、祖拜尔剧场、兰那罗、愚人众（须弥残党）。
【剧透分级说明】公开 / 剧情 / 隐藏 / 禁止（四级，含义见 center_setting.md）

【六大属性】体魄、灵巧、心智、感知、交涉、意志
【武器类型】单手剑、双手剑、弓、法器、长枪

【七、世界书条目（精简版）】
========================================

关键词：须弥, 教令院, 虚空, 草神
优先级：高
剧透：公开
内容：须弥是草元素的国度，雨林与沙漠并存。教令院是学术管理机构，六大学派中以知论派和因论派最为核心。进入本章时虚空系统仍被用于知识与日常事务，关闭须待对应剧情。大慈树王是前任草神，已消逝。纳西妲是现任草神，最年轻的神明。艾尔海森是书记官，卡维是著名建筑师，提纳里是巡林官，赛诺是大风纪官，柯莱是见习巡林员。教令院曾发生「造神计划」事件，大贤者阿扎尔被推翻，散兵（流浪者）被纳西妲收留。

关键词：赤王文明, 赫曼努比斯, 跋灵, 缄默之殿
优先级：中
剧透：剧情
内容：赤王文明是须弥沙漠地区的古代文明，赫曼努比斯为其重要人物。缄默之殿曾是复兴赫曼努比斯力量的组织，留下了两片蕴含智慧与神力的「跋灵」。赛诺和赛索斯均被植入跋灵，以凡人之身承受神明碎片。居勒什背叛缄默之殿，将赛诺带到教令院照养。巴穆恩去世后，赛索斯接任缄默之殿首领。赤王的「阿如」——即「永恒绿洲」——是这一文明留给后世的最后一件遗产。

关键词：兰那罗, 桓那兰那, 死域, 惟耶之实
优先级：中
剧透：剧情
内容：兰那罗是须弥雨林中的神秘生物，与森林和梦境有深层关联。桓那兰那是兰那罗的居所。死域是一种侵蚀生命的异常现象。惟耶之实是兰那罗牺牲记忆而结出的果实，可用于救助被死域侵蚀的人。拉娜与兰拉娜的羁绊是人与兰那罗建立深层联系的罕见案例。普通人无法见到兰那罗，除非其具有「童心」。

关键词：希穆兰卡, 话语构成, 三位魔女, 天命既定
优先级：低
剧透：剧情
内容：希穆兰卡是一个由「话语」构成的童话世界，妮露曾以「森林仙子」的身份进入其中。它由三位魔女创造——艾莉丝（魔女A）、亚斯妥曼瑟·芭比洛斯·崔斯梅姬斯图斯（魔女B）、安雅·玛丽·安德斯多特（魔女M）。这个世界中的法则与现实不同，居民的病症与「记忆和本我」有关。该世界与须弥的「知识」体系可能存在深层对应。其运转遵循「天命既定」：提瓦特人的命运会映射在虚假之天上，因此在其中改写结局便能抢占命运的轨迹——此机制的解释属禁止级，只可陈述已发生的事实，不可揭示原理。

关键词：世界树事件, 三月博士, 世界树, 阿如, 火神之心
优先级：高
剧透：隐藏
内容：世界树事件是一条跨地区因果链，**发生时机在玩家走完挪德卡莱段之后**，因此不属于须弥段（第 4 站）亲历的内容；须弥段与纳塔段的文档只呈现「危机前的状态」。顺序为：①挪德卡莱段，三月博士被击杀（他窃取三月权柄——赤月、霜月及一枚人造月髓，是「最自私自利」的那个切片）；②博士的部分灵魂通过地脉前往世界树，试图篡改世界树，威胁世界信息；③柯莱梦到「世界人物完全混乱」，这是预警；④柯莱体内的魔神残渣真身展开——花神残渣；⑤因发现及时，须弥人员转移及时，未发生大规模危害；⑥纳西妲为存续，改造赤王的「阿如」，将其从「永恒绿洲」转变为新的世界树，并备份信息；⑦向火神借用火神之心，烧毁被污染的世界树；⑧火神之心下落不明。

关键词：花神残渣, 柯莱, 魔神残渣, 花神, 魔鳞病
优先级：中
剧透：隐藏
内容：柯莱生而患有魔鳞病，被自称传教士的愚人众注入魔神残渣后废弃。该残渣的真身并非无名魔神，而是「花神残渣」——花神是须弥古老神明之一，与赤王、树王同列须弥三神。残渣长期被压制但从未被彻底清除，柯莱因此会做异常梦境。世界树事件中，正是花神残渣的真身展开，与柯莱「世界人物完全混乱」的梦一同构成预警，使须弥得以及时转移人员。可暗示病症、梦境与植物的异常共鸣；不可直说「花神」之名及其与赤王文明的关系。

关键词：草神之心, 雷神之心, 博士, 多托雷, 切片, 神之心
优先级：高
剧透：剧情
内容：须弥段收束时，两枚神之心经由纳西妲之手流向博士。其一为草神之心：博士的切片与纳西妲交换，纳西妲以此条件销毁了博士的其余所有切片。其二为雷神之心：它本由八重神子交给愚人众，再由散兵携带，被须弥大贤者用于造神计划，险些造出人造魔神；纳西妲经手后，将雷、草两枚神之心一并交给博士。至冬段开始时，已入女皇之手者为六枚（风、岩、雷、草、水，加冰神自持），火神之心下落不明。

· 本地区涉及的跨地区因果链：
  - 链 A（神之心的移交顺序）：雷神之心与草神之心在本地区完成收束——两枚一并交到博士手中。
  - 链 B（世界树事件）：因果顺序为「挪德卡莱 → 须弥 → 纳塔」，而八站线性顺序为「须弥(4) → 纳塔(6) → 挪德卡莱(7)」。因此本事件**不是玩家按线性顺序亲历的章节事件**，而是**玩家走完挪德卡莱之后才展开的后续**；本地区文档只写「危机前的状态」，事件全链见第七节世界书。
  - 链 E（散兵 / 世界树记忆）：他修改世界树删除自身犯下的错 → 普通人视角第六席空缺、他自己也不记得 → 旅行者属降临者、记忆未被改写 → 旅行者告知纳西妲、纳西妲转告他 → 此后代号「流浪者」，玩家可赋予其名字。本地区是该链的落点。
