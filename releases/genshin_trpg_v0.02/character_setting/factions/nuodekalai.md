# 挪德卡莱地区势力设定

> 本文回答“当地有哪些组织、它们承担什么职责、当前处于什么阶段”。人物个体资料见相邻目录的 `../characters/nuodekalai.md`。
> 具体行动以当前场景和已记录事实为准。组织设定不能自动生成阴谋、委托、敌对关系或玩家必须加入的立场。

## 地区定位与当前阶段

【地区定位】挪德卡莱（Nod-Krai）是位于至冬最南端、提瓦特边缘的自治区域。当地存在一种被称为「月矩力」的远古力量形式，比七元素力更古老；从全提瓦特各地汇聚而来的人们利用这种来自月亮的能源，为挪德卡莱注入了充沛活力。
【当前时间线】挪德卡莱篇进入阶段：狂猎仍在威胁当地，各方正在应对，法尔伽远征队尚未因本章结束返回蒙德。新杜林若已由回蒙德段实际产生可出现；旧稿中的击杀、归乡与危机结束描述须按真实进度启用，不作为抵达时全部既成事实。未核实的具体因果不补成正史。
【阶段阅读规则】正式采用《mainline-rules.md》及《timeline.md》的亲历路线。正文中仍以“已完成/已退位/已恢复/现状”记述的后期人物或危机结局，是到达对应节点后才启用的资料；不得据此跳过主线、提前授予NPC知识或把未来结果当成当前事实。
【关键地点】那夏镇、希汐岛、皮拉米达城、虚海望、浪浪湾、悠悠度假村。
【主要势力】本土势力：霜月之子、执灯人、伏尼契商会（秘闻馆）；外来势力：愚人众、狂猎、西风骑士团远征队、魔女会。

## 势力职责

| 势力 | 现有设定中的职责与边界 |
|---|---|
| **霜月之子与月之信仰** | 地方信仰及族群关系围绕霜月之子展开；神明身份、历史伤痕与人物知情边界按原文剧透等级处理。 |
| **执灯人** | 负责巡夜、灯塔及应对狂猎相关威胁；分队调查和路线记录可直接形成地区行动入口。 |
| **蛋卷工坊、秘闻馆与冒险家协会** | 连接工坊技术、地方情报与冒险活动，能提供日常及调查支线。 |
| **魔女会与愚人众** | 具有跨地区行动能力；具体目标、成员状态和彼此关系须以人物资料及时间线为准。 |
| **蒙德远征队** | 法尔伽率领的远征队在此活动，是蒙德与挪德卡莱因果链的重要组成；不要把其视作与当地危机无关的背景摆设。 |

## 主持使用边界

- 先按玩家当下所在位置、已建立关系和组织公开职责判断谁能合理介入；不能因为名单里存在某势力，就让它突然出现。
- 组织可以彼此合作、冲突或保持距离，但具体关系须有当前阶段和已知事实支持。
- 当异常原因未明时，优先核对地区历史、地脉/元素、深渊与天理相关背景；普通人祸须有具体证据和可信动机。
- 地区主线优先级与推进要求见 `../hooks/nuodekalai.md` 及 `../../docs/rules/mainline-rules.md`。
