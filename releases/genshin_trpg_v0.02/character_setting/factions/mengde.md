# 蒙德地区势力设定

> 本文回答“当地有哪些组织、它们承担什么职责、当前处于什么阶段”。人物个体资料见相邻目录的 `../characters/mengde.md`。
> 具体行动以当前场景和已记录事实为准。组织设定不能自动生成阴谋、委托、敌对关系或玩家必须加入的立场。

## 地区定位与当前阶段

【地区定位】风元素的国度，崇尚自由。西风骑士团是主要管理机构，西风教会与冒险家协会为重要的社会支柱。
【当前时间线】蒙德篇进入阶段：风龙危机尚未解决，风灾正在影响居民、道路与城防。琴代理骑士团事务，法尔伽远征未归；特瓦林尚未净化。温迪身份和风神之心的去向须按事件揭示。杜林危机仍留在回蒙德插入段，不替代首次风龙主线。
【阶段阅读规则】正式采用《mainline-rules.md》及《timeline.md》的亲历路线。正文中仍以“已完成/已退位/已恢复/现状”记述的后期人物或危机结局，是到达对应节点后才启用的资料；不得据此跳过主线、提前授予NPC知识或把未来结果当成当前事实。
【关键地点】蒙德城、西风大教堂、西风骑士团总部、晨曦酒庄、奔狼领、龙脊雪山、风起地、风龙废墟、清泉镇、猫尾酒馆、誓言岬
【主要势力】西风骑士团、西风教会、冒险家协会、晨曦酒庄、劳伦斯家族旧部、愚人众（暗中活动）、深渊教团（暗中活动）

## 势力职责

| 势力 | 现有设定中的职责与边界 |
|---|---|
| **西风骑士团** | 蒙德的主要治理与防务机构；当前由琴代理日常事务，大团长法尔伽仍在远征。风龙危机期间负责组织救援、调查与城防。 |
| **西风教会** | 承担宗教仪式、教会服务与民众照护；芭芭拉是祈礼牧师。日常照护不能替代风龙危机的调查与处理。 |
| **冒险家协会** | 发布委托并联络旅行者与本地冒险者，可提供进入调查的现实入口；普通委托不得取代地区主线。 |
| **晨曦酒庄** | 迪卢克经营的酒庄及商贸据点，也与蒙德城外的交通和人脉相连；不因其主人身份自动掌握全部情报。 |
| **劳伦斯家族旧部** | 旧贵族遗留的社会与政治关系；优菈与家族旧部的立场须按具体人物和场景呈现，不默认其正在发动阴谋。 |
| **愚人众** | 在蒙德暗中活动的外部势力；仅在已有线索支持时介入事件。 |
| **深渊教团** | 与风龙危机及深渊侵蚀相关的敌对势力；其行动须由证据逐步揭示，不能把所有异常都直接归给教团。 |

## 组织设定原文

组织名：三位魔女与希穆兰卡
【身份】创造童话世界「希穆兰卡」的三位魔女会成员
【成员】艾莉丝（魔女 A，可莉的母亲）、亚斯妥曼瑟·芭比洛斯·崔斯梅姬斯图斯（魔女 B）、安雅·玛丽·安德斯多特（魔女 M）
【出现地点】希穆兰卡（童话世界）；相关线索散见于蒙德与须弥
【设定】三位魔女创造了「希穆兰卡」这一童话世界。回蒙德段中，旅行者一行人在其中完成了对小杜林的安抚——这一步是「以善龙顶替恶龙命数」的关键操作。
【剧透等级】剧情



## 主持使用边界

- 先按玩家当下所在位置、已建立关系和组织公开职责判断谁能合理介入；不能因为名单里存在某势力，就让它突然出现。
- 组织可以彼此合作、冲突或保持距离，但具体关系须有当前阶段和已知事实支持。
- 当异常原因未明时，优先核对地区历史、地脉/元素、深渊与天理相关背景；普通人祸须有具体证据和可信动机。
- 地区主线优先级与推进要求见 `../hooks/mengde.md` 及 `../../docs/rules/mainline-rules.md`。
