# 至冬地区势力设定

> 本文回答“当地有哪些组织、它们承担什么职责、当前处于什么阶段”。人物个体资料见相邻目录的 `../characters/zhidong.md`。
> 具体行动以当前场景和已记录事实为准。组织设定不能自动生成阴谋、委托、敌对关系或玩家必须加入的立场。

## 地区定位与当前阶段

【地区定位】至冬国是位于提瓦特大陆北境的冰雪国度，由冰之神安娜丝塔霞·费奥多罗夫娜·雪奈茨娜娅统治。至冬是七国中最寒冷、环境最严酷的国家，也是愚人众的发源地与总部所在地。与蒙德的自由、璃月的契约不同，至冬的核心理念围绕着「抗争」与「团结」展开——在这片不被神明眷顾的国度，人们相信团结在女皇身边抗争到底，定会迎来更好的新世界。
【当前时间线】至冬篇进入阶段：终章围绕对抗神明及其秩序的冲突展开，结果尚未发生。具体神之心持有者、执行官状态与已解锁知识，先核对前章实际记录；不得仅凭抵达就补齐计划、授予全部秘密或预定玩家效忠对象。未核实的终局细节须另作明确同人裁定。
【阶段阅读规则】正式采用《mainline-rules.md》及《timeline.md》的亲历路线。正文中仍以“已完成/已退位/已恢复/现状”记述的后期人物或危机结局，是到达对应节点后才启用的资料；不得据此跳过主线、提前授予NPC知识或把未来结果当成当前事实。
【关键地点】至冬堡、格鲁波夫（愚人之城）、白冕宫（白沙皇陵寝）、基捷（至冬第一座城市）、贝洛沃迪港、卓沃戈列、伏尔霍凡、切纳雷卡、科洛列夫茨基剧院。
【主要势力】愚人众（涵盖至冬政务与军事的方方面面，拥有七国最强的武力）、至冬皇室、冬契军、皇都评议会、妖精氏族（没落但仍影响至冬发展）。

## 势力职责

| 势力 | 现有设定中的职责与边界 |
|---|---|
| **至冬皇室** | 由冰之女皇统治，具有终章核心政治地位；玩家的立场和效忠对象必须由玩家自行决定。 |
| **愚人众执行官** | 承担跨国行动与神之心相关计划；具体席位、存续状态和已取得信息先核对前章记录。 |
| **冬契军** | 重要军事力量，负责至冬本土与皇室相关安全；不要仅凭制服或阵营标签推断个人行动。 |
| **皇都评议会** | 至冬本土政治体系的一部分；其权限、派系和具体决策以场景资料逐步显现。 |
| **妖精氏族** | 曾深刻影响至冬历史，当前势力衰落但仍与社会和历史有关；禁止级背景不能直接揭露。 |
| **至冬文艺界与冒险家协会** | 为终章提供民间生活、公开信息及普通人的视角，不能让终章只剩高层密谈。 |

## 主持使用边界

- 先按玩家当下所在位置、已建立关系和组织公开职责判断谁能合理介入；不能因为名单里存在某势力，就让它突然出现。
- 组织可以彼此合作、冲突或保持距离，但具体关系须有当前阶段和已知事实支持。
- 当异常原因未明时，优先核对地区历史、地脉/元素、深渊与天理相关背景；普通人祸须有具体证据和可信动机。
- 地区主线优先级与推进要求见 `../hooks/zhidong.md` 及 `../../docs/rules/mainline-rules.md`。
