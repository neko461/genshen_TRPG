# 纳塔地区势力设定

> 本文回答“当地有哪些组织、它们承担什么职责、当前处于什么阶段”。人物个体资料见相邻目录的 `../characters/nata.md`。
> 具体行动以当前场景和已记录事实为准。组织设定不能自动生成阴谋、委托、敌对关系或玩家必须加入的立场。

## 地区定位与当前阶段

【地区定位】火元素的国度，由六大部族合并而成的盟誓之邦，信奉「战争」之神；核心命题是与深渊的长期对抗，以及「古名」与「夜神之国」的生死轮回体系。
【当前时间线】纳塔篇进入阶段：深渊入侵与夜神之国相关危机尚未收束，六英雄相关行动须在本章逐步实现。玛薇卡仍在组织抵抗；队长不得预先套用已融合、坐困王座而无法行动的后期状态。古名、死亡与地脉的秘密须有来源并分阶段揭示。
【阶段阅读规则】正式采用《mainline-rules.md》及《timeline.md》的亲历路线。正文中仍以“已完成/已退位/已恢复/现状”记述的后期人物或危机结局，是到达对应节点后才启用的资料；不得据此跳过主线、提前授予NPC知识或把未来结果当成当前事实。
【关键地点】圣火竞技场、夜神之国、奥奇坎纳塔、回声之子、悬木人（维茨特兰）、流泉之众（梅兹特利）、烟谜主（米克特兰）、花羽会（特拉洛坎）、沃陆之邦、安饶之野、镜璧山、浪浪湾、悠悠度假村。
【主要势力】纳塔六大部族、愚人众（以「队长」卡皮塔诺为代表的外来势力）、深渊

## 势力职责

| 势力 | 现有设定中的职责与边界 |
|---|---|
| **六部与六英雄** | 纳塔以部族和勇士协作应对危机；各部的责任、地域和古名按角色及时间线资料处理。 |
| **龙伙伴与纳塔NPC** | 当地人与龙的关系构成日常和行动资源；不把龙族简化为可随意招募的坐骑或工具。 |
| **在纳塔活动的外来关键人物** | 卡皮塔诺等外来角色有自身目标；其出现不自动改变纳塔人的主体行动。 |
| **深渊势力** | 深渊入侵是地区核心威胁，与夜神之国的维系直接相关；其性质须由既有世界设定与现场证据支撑。 |

## 主持使用边界

- 先按玩家当下所在位置、已建立关系和组织公开职责判断谁能合理介入；不能因为名单里存在某势力，就让它突然出现。
- 组织可以彼此合作、冲突或保持距离，但具体关系须有当前阶段和已知事实支持。
- 当异常原因未明时，优先核对地区历史、地脉/元素、深渊与天理相关背景；普通人祸须有具体证据和可信动机。
- 地区主线优先级与推进要求见 `../hooks/nata.md` 及 `../../docs/rules/mainline-rules.md`。
