# genshen_TRPG_v0.02

正式方向是 DeepSeek Harness 中的自由对话跑团：玩家描述行动，GM 主持，插件处理角色、判定和存档。

## 打开 AI 跑团

双击根目录“启动AI跑团.cmd”。它先检查真实 DSH 工具，再运行 npx @deepseek-ai/dsh web --port 3081，自动打开本次有效的页面。保持启动窗口运行；插件源码通过 link: 挂载，修改后重新启动即可加载，不必重新发布或升级插件包。

若已启动，不要再重复运行。重新加载时，在原启动终端按 Ctrl+C，待退出后再启动。每次启动的认证链接可能变化，应使用当次自动打开的页面；旧标签、收藏地址或仅输入端口地址可能无法通过认证。

进入 DSH 后选择本工作区 E:\genshen_TRPG\v0.01，新建聊天，让 GM 先调用 trpg_char 的 opening，明确 mode=solo 与独立 slot，通过对话确认角色后建卡。不要调用 demo。详细主持标准见《主持手册》“开场与主持规范”部分。当前已验证工具接口与页面打开，完整模型主持体验仍需实际验收。

## 开发测试入口

“启动首轮测试.cmd”与 17891 端口是早期固定场景测试台，不作为正式 AI 跑团入口。《docs/测试/第一轮测试指南.md》只用于该测试台的规则回归。

需要 Node.js 22+。运行时与 DSH 适配代码位于 code/dsh-trpg/；实际存档位于 save/slots/。v0.02 已通过 181 项自动化测试，并在完整重启后的 DSH 宿主及原有蒙德存档上完成实机复核。详见版本说明与实机回归记录。

仓库只包含源码、设定、规则与测试资料。本机存档、用户资料、依赖目录、备份及配置迁移副本通过 `.gitignore` 排除，不随源码上传。新电脑需先在 `code/dsh-trpg/` 安装依赖，再按该目录 README 将插件挂载到本机 DSH；不能直接沿用开发机的绝对路径。

本版本改动见[改动记录-v0.02](docs/记录/改动记录-v0.02.md)；历史修改见[改动记录-v0.01](docs/记录/改动记录-v0.01.md)。标签支持结构化 modifier:-1，不必将负面标签改成优势；已有角色可通过 setTags 修正。

v0.02 使用3081端口，避免与仍占用3080的旧实例冲突。请使用本目录启动后自动打开的新页面。

同一套DSH聊天目录应只运行一个实例。3080与3081共用会话写锁，不能用更换端口解决占用错误；当前保留3081。启动器会检测这两个端口并阻止重复启动，原根目录启动入口也已转发到本目录。端口检查不是任意端口或其他机器的全局实例管理。

剧情检定现支持DSH原生提交回答及骰子动画，见《docs/使用/玩家掷骰与动画说明.md》。已有聊天让GM重读“公开检定的告知”即可沿用剧情，不重掷旧结果。
