## 总纲：本跑团的基本框架（来自 A-1 裁定）

| 项 | 裁定 |
|---|---|
| 玩家身份 | **冒险家协会的冒险家** |
| 角色卡自由度 | 神之眼、武器、元素、出身国家可自行挑选 |
| 旅行者 | **可交互角色之一**，不是玩家自捏角色 |
| 结识地点 | **在蒙德结识旅行者** |
| 同行范围 | **随旅行者走完八站（七国 + 挪德卡莱）** |
| 关系亲密度上限 | **不高于派蒙** |
| 旅行者第一要务 | **寻找血亲**（不可直接表现） |

**这一条是全局主轴，直接覆盖 B 类时间线问题**：本战役的「现在」不是「后主线」，而是**与旅行者的旅程同步、按顺序推进**。九份地区文档里的「【当前时间线】后主线时期」全部需要改写 —— **改写方向已定为「乙」**，见 §5-1。

## A-1　旅行者所在位置 ✅

**裁定要点**
- 玩家以冒险家协会冒险家身份入场，与旅行者在**蒙德**结识。
- 此后随旅行者依次走完七国：蒙德 → 璃月 → 稻妻 → 须弥 → 枫丹 → 纳塔 → 挪德卡莱。
- 旅行者是可交互 NPC 之一，关系上限「不高于派蒙」。
- 旅行者的**第一要务是寻找血亲**，但**不能直接表现出来**（即：AI 不得让旅行者主动倾诉、不得把「找哥哥/妹妹」当作可商议的目标；只能通过行为细节流露）。

**由此覆盖/改写的旧内容**
- `center_setting.md`「旅行者已离开璃月」→ 需改为「旅行者与玩家同行，当前已抵达/正在某国」，或改为由时间轴逐国标注的形态。
- `liyue.md` 标题「后主线时期」→ 需改为「与旅行者同行期间」。
- 其余七份地区文档的「后主线时期」→ 同上。
- **`center_setting.md` 的「璃月，岩王帝君退位后一年」仍然可用**（这是时间轴上璃月段的具体坐标），但需要补上它对应旅行者行程的哪一段。

**待你确认的细节（见 §5-1）**
- 旅行者走完全程后，战役是否继续？（即存在「后主线阶段」吗）
- 若玩家中途离队或选择留在某国，如何处理？

## A-2　阿蕾奇诺上位经过 ✅

> **本条经过一次修正**。首次裁定误把佩露薇利当作「童年玩伴」，现已更正。**以下为最终版。**

**裁定：人物关系**

| 角色 | 身份 |
|---|---|
| **佩露薇利** | **阿蕾奇诺的本名**（即阿蕾奇诺就是佩露薇利，同一人） |
| **克雷薇** | **阿蕾奇诺（佩露薇利）的童年玩伴**，死于童年时期壁炉之家孩子们之间的决斗 |
| 库嘉维娜 | 前任「仆人」，被取代 |
| 阿蕾奇诺 | 取代库嘉维娜者；女皇赦免其弑母罪孽并**赐予「阿蕾奇诺」这个名字** |

**因此完整脉络为**：

```
佩露薇利（本名）在壁炉之家长大
  → 童年玩伴克雷薇死于孩子间的决斗
  → 后来弑杀前任「仆人」库嘉维娜（「母亲」）
  → 冰之女皇赦免其罪，赐名「阿蕾奇诺」
  → 继任愚人众执行官第四席「仆人」
```

**由此确定的写法**
- 「佩露薇利成功刺杀库嘉维娜」**不成立**——刺杀者是佩露薇利即阿蕾奇诺本人，但记述时应使用「佩露薇利（即后来的阿蕾奇诺）」或以「阿蕾奇诺（本名佩露薇利）」标注，避免读者误为两人。
- `zhidong.md` 的「冰之女皇赦免了她弑母的罪孽，赐予她阿蕾奇诺的名字」✅ **成立，保留**。
