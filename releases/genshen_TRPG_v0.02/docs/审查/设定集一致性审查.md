### A-1　旅行者所在位置：三份文档三种说法

| 位置 | 原文 |
|---|---|
| `center_setting.md` | 「旅行者已离开璃月。」 |
| `liyue.md` 地区定位 | 后主线时期 |
| `liyue.md` 钟离·关系 | 「达达利亚以为他是凡人朋友」——未涉及离开 |
| `liyue.md` 钩子二 | 「凝光派遣刻晴带队前往调查」 |

**冲突点**：`liyue.md` 标题写「后主线时期」，但正文无任何一句交代旅行者去了哪、走了多久。`center_setting` 说「已离开璃月」，而其他八国文档全部写「后主线时期」，隐含旅行者已完成七国旅程。

**待裁**：
1. 「后主线」是指**旅行者已走完七国**（那么璃月的时间锚点必须从「离开璃月」上调到与七国同期），还是
2. 指**旅行者刚离开璃月、正前往须弥**（那么蒙德/稻妻/须弥/枫丹/纳塔的「后主线」全部不成立，得整体下调）？

## 二、B 类：时间线（你已点名的重点）

### B-0　当前的根本问题

九份设定文档，**每一份都有自己的「当前时间线」，但九份的「现在」不是同一个时刻**。没有任何一份文档定义「现在」是哪一年、距帝君退位多久、距坎瑞亚灾变多久。结果是：

- 需要跨地区取用的人物状态无法共存（A-3 法尔伽、A-5 卡皮塔诺）。
- AI 跑团时无法判断「某个钩子还能不能用」，只能二选一或含糊其辞。
- `center_setting.md` 的「璃月，岩王帝君退位后一年」是唯一一个具体坐标，但它只覆盖璃月。

### B-1　各文档现有的时间锚点

| 文档 | 明确写出的时间锚点 | 模糊处 |
|---|---|---|
| `center_setting.md` | 璃月，帝君退位后一年 | 与其他八国的关系未定义 |
| `liyue.md` | 「后主线时期。帝君退位已过一段时间」；海灯节兹白三魂重合 | 「后主线」相对谁？ |
| `mengde.md` | 「后主线时期。法尔伽率远征军已回归」 | 远征历时多久、何时回归 |
| `daoqi.md` | 「后主线时期。锁国令与眼狩令已废除；神樱大祓已完成」 | 距废除多久 |
| `xumi.md` | 「后主线时期。纳西妲全面执政，教令院改革推进」 | 造神计划距今多久 |
| `fengdan.md` | 「后主线时期。预言危机已解决，芙宁娜退位为凡人」 | 退位距今多久 |
| `nata.md` | 「后主线时期。六英雄已觉醒并击退深渊入侵」 | 击退距今多久 |
| `zhidong.md` | 「后主线时期……部分执行官已离开或陨落」 | 队长陨落时间点与纳塔不同步 |
| `nuodekalai.md` | 「后主线时期。桑多涅已率部进驻；哥伦比娅已回到挪德卡莱；法尔伽**正**深入探索」 | 「正」是给谁的「正」 |

**共同缺口**：没有任何文档给出**具体年代或相对月数**。因此「A 发生在 B 之前多久」这类判断无处落地。

### B-2　必须先定的一件事：主线时间轴采用哪一版
