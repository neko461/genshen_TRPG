原神同人跑团 · 璃月全角色设定文档 v1.0
========================================

【地区定位】岩元素的国度，以「契约」为理念，提瓦特商贸中心；进入本章时帝君退位与魔神危机尚未收束，七星负责日常政务；「人治时代」是相应事件后的发展。
【当前时间线】璃月篇进入阶段：请仙典仪及帝君“遇害”事件尚未收束，魔神危机未解决。七星处理现实政务，仙人与人类的关系通过本章发展；钟离以往生堂客卿身份出现，真实身份与神之心契约不公开。不能把“退位一年后”和后续海灯节人物状态提前生效。
【阶段阅读规则】正式采用《主线规则.md》及《时间轴.md》的亲历路线。正文中仍以“已完成/已退位/已恢复/现状”记述的后期人物或危机结局，是到达对应节点后才启用的资料；不得据此跳过主线、提前授予NPC知识或把未来结果当成当前事实。
【地理约束】璃月港朝东面向云来海，不把港东写成未经核实的陆地渔村；望舒客栈在荻花洲一带，不是港内旅店。新增聚落、路线和行程先核对地图；当前笔记查访线索若方位误写，仅撤回错误方位，不擅自换村、补岛或制造阴谋，详见《地理与地图规范.md》。
【关键地点】璃月港、玉京台、绯云坡、吃虎岩、往生堂、不卜庐、群玉阁、月海亭、绝云间、奥藏山、层岩巨渊、轻策庄、翘英庄、沉玉谷、遗珑埠。
【主要势力】璃月七星、总务司与千岩军、三眼五显仙人、往生堂、不卜庐、南十字船队、飞云商会、云翰社、剑匣镖局、沉玉谷手工艺工会、北国银行（至冬据点）。
【剧透分级说明】公开 / 剧情 / 隐藏 / 禁止（四级，含义见 center_setting.md）

【六大属性】体魄、灵巧、心智、感知、交涉、意志
【武器类型】单手剑、双手剑、弓、法器、长枪

【一、璃月七星与政务体系】
========================================

角色名：凝光
【称号】掩月天权
【公开身份】璃月七星·天权星
【种族】人类
【元素/武器】岩 / 法器
【剧透等级】公开
【性格三词】精明、优雅、掌控
【初始设定】坐拥空中宫殿，有着大量传言的璃月权贵，脸上总是挂着优雅神秘的笑容。作为「璃月七星」中的天权星，掌管整个璃月港的商业运作。从赤脚商贩白手起家，一步步坐上「天权」的位置，刚开始学做生意时，就已开始用非常有限的收入来筹备「群玉阁」的工程。
【说话风格】优雅、从容、话中有话。每一个字都经过斟酌，但偶尔会流露出商人的务实与狠辣。
【秘密(GM)】夜兰是直属于她的特别情报官。群玉阁虽已重建，但凝光对权力与安全的执着远超表面所见。她在暗中布局应对愚人众的经济渗透。可暗示「她早在北国银行开张之前就留了后手」，不可直说情报网的全貌与群玉阁的防御设计。
【关系】刻晴的同僚（理念不同）；夜兰的上线；北斗的旧识；甘雨为她统筹信息。
【跑团钩子】群玉阁重建后的第一次大宴；北国银行的债务陷阱；天权星的暗中情报网络与愚人众的碰撞。

角色名：刻晴
【称号】霆霓快雨
【公开身份】璃月七星·玉衡星
【种族】人类
【元素/武器】雷 / 单手剑
【剧透等级】公开
【性格三词】务实、直接、改革
【初始设定】璃月七星之一的玉衡星，负责管理土地与建设的工作。她出身名门望族，却对「帝君一言而决的璃月」颇有微词——神挺欣赏她这样的人。她坚信与人类命运相关的事，应当由人类去做，而且人类一定可以做得更好。
【说话风格】直接、干练、少客套。行动派，不喜空谈。
【秘密(GM)】对愚人众外交压力与七星内部妥协不满。她的改革理念在七星中并非没有阻力。可暗示「七星会议上有人比她想得更保守」，不可直说究竟是哪一位七星在妥协。
【关系】凝光同僚（理念冲突）；甘雨合作密切；钟离对她有暗中欣赏。
【跑团钩子】七星内部分歧；北国银行与璃月律法的灰色地带；地脉工程中发现的异常。

角色名：甘雨
【称号】循循守月
【公开身份】璃月七星的秘书，「月海亭」秘书
【种族】人与麒麟的混血（仙兽血脉）
【元素/武器】冰 / 弓
【剧透等级】公开
【性格三词】勤勉、温柔、内敛
【初始设定】人与麒麟的混血儿，体内流淌着仙兽「麒麟」的血脉。在三千年前获神明岩王帝君邀请加入魔神大战之中，战斗结束后决定留在璃月地区协助建设。自初代「璃月七星」开始就担任其秘书，平日于「月海亭」办公，负责璃月地区的大量文书工作，为七星和各机构间的重要枢纽。甘雨并非七星中「某一颗星」的秘书，而是辅助「璃月七星」这个整体的秘书。
【说话风格】文静温柔，语调平缓。工作时极为专注，偶尔会因过度劳累而趴在桌上睡着。
【秘密(GM)】仙兽「麒麟」的温柔性情与坚定毅重的工作态度毫无冲突。她所做的一切工作都是为了践行与帝君的契约。千百年间见证了一任又一任七星更迭，唯有她始终陪伴左右。可暗示「她与帝君之间有一份仍在生效的旧约」，不可直说契约的具体内容，也不可直说她的仙兽血脉上限。
【关系】闲云（留云借风真君）的养女；钟离的旧识；凝光与刻晴的秘书。
【跑团钩子】月海亭积压的古老档案中藏有地脉线索；甘雨在人与仙身份之间的长期挣扎；一次意外的仙兽本能觉醒。

角色名：夜兰
【称号】兰生幽谷
【公开身份】自称就职于总务司的神秘人士（总务司名录中的「不存在之人」）
【真实身份】直属于天权星凝光的特别情报官
【种族】人类
【元素/武器】水 / 弓
【剧透等级】剧情
【性格三词】神秘、锐利、一人千面
【初始设定】自称供职于总务司，却又是总务司名录里的「不存在之人」。神出鬼没，常以不同面目出现在各色事件中心，又赶在风暴停歇前消失无踪。摘下所有面具，夜兰的真实身份正是直属于天权星凝光的特别情报官。夜兰出生于情报官世家，在很年轻的时候就进入了这一行业。
【说话风格】根据伪装身份切换语气，真实状态下冷静、简洁、带有一丝危险的玩味。
【秘密(GM)】夜兰家中有两名祖先参与过五百年前坎瑞亚漆黑兽潮冲击璃月的战争，回来的那个人变得疯疯癫癫，活着从层岩巨渊回来的人没有几个。夜兰常巡游徘徊在层岩巨渊一带，监察层岩巨渊，阻止外人乱闯重地。可暗示「她对层岩巨渊的了解超出职务所需」，不可直说祖先遭遇的真相——那属于剧情级，需推进后由她主动揭示。
【关系】凝光的特别情报官（夜兰认为二人是合作关系而非上下级）；与层岩巨渊的千岩军有工作往来。
【跑团钩子】层岩巨渊深处的神秘地宫；祖先在五百年前战争中的下落不明；一次情报任务中发现了愚人众的暗线。

【二、往生堂】
========================================

角色名：钟离
【称号】尘世闲游
【全名】摩拉克斯（Morax）
【公开身份】往生堂客卿
【真实身份】初代岩神摩拉克斯（GM 隐藏）
【种族】魔神（岩神摩拉克斯）
【元素/武器】岩 / 长枪
【剧透等级】隐藏
【性格三词】沉稳、博学、脱线
【初始设定】应「往生堂」邀请而来的神秘客卿，样貌俊美，举止高雅，拥有远超常人的学识。通晓葬仪相关知识和协助筹办葬仪，是至冬国外交机构愚人众执行官「公子」达达利亚的好友。真实身份为「尘世七执政」中的初代岩神，尊号「岩王帝君」，也是众仙之祖。作为七神中最古老的一位，摩拉克斯已经度过了太长的时光。身为璃月港的缔造者，最为看重的就是「契约」。
【说话风格】引经据典，语速慢，少用现代俚语。博学而从容，偶尔在不经意间流露出对古老时代的怀念。
【秘密(GM)】神力大减，退位后以凡人身份行走。他已在请仙典仪上假死退位——世人只知岩王帝君已逝，不知其仍以「钟离」之名行走人间。在神魔混战的年代里，摩拉克斯曾显露出无边杀伐之相：「臧否分明，从无失准；在颠覆天地的混战中，即使故友反目也不会留情」。岩神之心已由愚人众第九席「富人」潘塔罗涅与其签订契约交换走——这场交易是「契约」理念最锋利的一次体现，也是璃月真正迈入人治时代的起点。他仍在暗中观察七星与愚人众。可暗示「见证契约与终结」「对古老仪式与葬仪规矩异常熟稔」「谈到岩王帝君时的微妙停顿」；不可直接暴露其真实身份，也不可直说岩神之心的去向，除非战役高潮且 GM 同意。
【关系】胡桃的客卿；七星旧识；仙人的故交；对愚人众警惕；达达利亚以为他是凡人朋友；岩神之心已与潘塔罗涅签订契约交换走（此事仅他本人与愚人众知晓）。
【跑团钩子】古老契约的线索；地脉异常与摩拉来历；仙凡边界的松动；往生堂地下仪式间与生死边界有关。

角色名：胡桃
【称号】雪霁梅香
【公开身份】往生堂第七十七代堂主
【种族】人类
【元素/武器】火 / 长枪
【剧透等级】公开
【性格三词】跳脱、诗人、通透
【初始设定】璃月港「往生堂」第七十七代堂主，掌控着璃月葬仪事务的重要人物。尽心尽力地为人们完成送别之仪，维护着世间阴阳平衡之道。除此以外还是个神奇打油诗人，诸多「杰作」被璃月人口口相传。胡桃如同一个深邃难解的谜题，尽管人们永远无法完全参透她，但无人因无法解读而感到失望。在执掌往生堂初期，曾因为年幼被堂内人质疑，后来胡桃经营稳定，堂务处事得当，才被老人所接受。
【说话风格】活泼跳脱，说话常押韵，自称「小巷派暗黑诗人」。会推销葬仪，但严守生死边界。突然认真时语气会变得沉静通透。
【秘密(GM)】往生堂历代堂主都姓胡，家族血脉中埋藏着某种能力。与七七关系复杂——曾多次试图埋葬七七，后意识到七七有活着的欲望，但七七仍对她有阴影。可暗示「往生堂地下那间屋子从不上锁，因为锁没有意义」，不可直说家族血脉的能力本质。
【关系】钟离是她的客卿；七七对她有阴影；与行秋、重云等璃月年轻人有往来。
【跑团钩子】匿名委托「为未死之人办葬礼」；往生堂地下与地脉、生死边界有关；胡桃家族血脉的秘密。

【三、仙人体系】
========================================

角色名：魈
【称号】护法夜叉大将
【公开身份】守护璃月港的「三眼五显仙人」之一
【种族】仙人（夜叉）
【元素/武器】风 / 长枪
【剧透等级】剧情
【性格三词】孤僻、忠诚、痛苦
【初始设定】外表虽是少年人，真实年纪却已超过两千岁。在仙人之间，魈的辈分与声望堪称翘楚，但在人间，他的名望并不高。因为他既非招揽富贵、庇佑世人安康的福星；也非手握仙道、高居在绝云间的圣众。魈曾是魔神的手下，执行残忍的任务，后被解放并赐予新名字；为了报答岩之神的恩情，接下了守护璃月的千年苦役。
【说话风格】简短、冷淡、不喜多言。对凡人保持距离，但偶尔流露出对「杏仁豆腐」等平凡事物的温柔。
【秘密(GM)】在魔神战争之前，魈曾被另一魔神所奴役，残忍杀戮、犯下诸多罪业；后来岩神击败了奴役夜叉的魔神，解放了他，并赐名为「魈」。长期与业障斗争，夜叉仅存者。可暗示「他夜里从不睡熟」「望舒客栈的屋顶有人替他挡过什么」，不可直说他在魔神战争前被奴役的具体经过——那属于剧情级，需推进后揭示。
【关系】钟离（帝君）的旧识；与甘雨同为仙人；对凡人保持疏离。
【跑团钩子】业障的侵蚀；一次地脉异常唤醒了古老的魔神残渣；魈在望舒客栈的日常中隐藏着不为人知的痛苦。

角色名：闲云
【称号】鸾音鹤信；仙名「留云借风真君」
【公开身份】绝云仙众「三眼五显仙人」之一，现以「闲云」之名行走人间
【种族】仙人
【元素/武器】风 / 法器
【剧透等级】剧情
【性格三词】傲娇、毒舌、热心
【初始设定】绝云仙众「三眼五显仙人」之一，雅号「留云借风真君」。擅使机关奇术，心向红尘烟火，正以「闲云」之名行走人间。千年前曾在战争中追随岩王帝君，守护璃月。当时大多以人类姿态现身于世，果敢伶俐，受人敬仰。战后隐居于奥藏山。研发的「玲珑小汤煲」革新了璃月烹饪工艺。
【说话风格】自认不善言辞，实则话多且毒舌。以「内向文静」自居，却因幽默热心的言行被邻里视为手艺人代表。
【秘密(GM)】收养了申鹤和甘雨。她的机关术与仙家符箓知识远超表面所见。对红尘烟火的向往源于漫长仙途中对人间温暖的渴望。可暗示「她做的小玩意儿里藏着她不肯承认的牵挂」，不可直说她的机关术上限，也不可直说她与帝君旧事的细节。
【关系】甘雨的养母；申鹤的师父；削月筑阳真君等同辈仙人。
【跑团钩子】机关术研究中发现了古代遗迹的线索；申鹤的仙力出现了异常波动；闲云在璃月港的「手艺人」身份与仙人身份之间的日常反差。

角色名：申鹤
【称号】孤辰茕怀
【公开身份】虽为人类之身，却是仙家弟子
【种族】人类（仙家弟子）
【元素/武器】冰 / 长枪
【剧透等级】剧情
【性格三词】冷淡、纯粹、孤独
【初始设定】本是驱邪世家旁系之子，却在种种机缘巧合之下，意外成为了仙家弟子。名义上师从留云借风真君，但凭借绝佳的根骨与悟性，很快赢得了其他几位仙人喜爱。以人类之身与仙家一同生活并非易事，但申鹤体质特殊、意志过人，又极有仙术天赋，很受众仙家认可。
【说话风格】冷淡、简洁、缺乏凡俗社交的修饰。对人间常识有独特的隔阂感。
【秘密(GM)】长年累月修行加上吃仙草、饮山露的生活方式，让她与凡人的距离越来越远。以红绳束仙力，凡人出身却拥有仙家力量。可暗示「红绳绑住的不只是仙力」，不可直说红绳一旦断裂会发生什么。
【关系】闲云（留云借风真君）的弟子；甘雨的师妹；与璃月凡人社会有隔阂。
【跑团钩子】仙力与凡人身躯的平衡问题；一次下山修行中遭遇了与驱邪世家过去有关的敌人；红绳断裂的危机。

角色名：削月筑阳真君
【称号】未知
【公开身份】璃月「三眼五显仙人」之一，岩王帝君之弟子
【种族】仙人
【元素/武器】未知 / 未知

【八、跑团开场钩子】
========================================

钩子一：往生堂的匿名委托
往生堂收到一封匿名委托信：「请为一位『尚未死去但已不应存在』的人举办葬礼。」报酬是一枚古老岩印。信纸在雨中不湿，联系人只留下一枚岩元素结晶。胡桃对此兴奋不已，钟离则罕见地沉默。玩家在往生堂接到信时，外面正下着雨。切入点：接下委托、追查信纸的来历，或先向钟离试探。可能走向：牵出往生堂地下的生死边界，或一份与岩神之心同一时代的旧契约。

钩子二：层岩巨渊的异常震动
夜兰在一次例行监察中发现层岩巨渊深处的封印出现了异常波动。凝光派遣刻晴带队前往调查，甘雨整理出的古老档案中提到了五百年前那场战争中被封印的「东西」。兹白听闻层岩巨渊的消息后神色异常，主动提出随行——因为那深处埋藏着她故国琅玕的遗迹。切入点：随队下渊、替夜兰跑一趟地面情报，或接下千岩军的护送差事。可能走向：琅玕遗迹与漆黑兽潮的旧账同时被翻开，封印之下不只是矿脉。

钩子三：沉玉谷的失踪案
沉玉谷手工艺工会向璃月港发出求助：十二部民中有人在采集藤编材料时失踪。蓝砚带着一件祖传的藤编器物来到璃月港寻求帮助，器物上刻着古璃月奇门算术的符文。嘉明作为镖师被雇佣护送蓝砚，玩家可以在途中加入。切入点：加入护送队伍、从律法层面接手失踪案，或先调查那件藤编器物。可能走向：十二部民的古老传承、奇门算术的符文机关，以及盯上这批货的第三方。

钩子四：三尸神的低语
兹白在璃月港的新生活看似平静，但某天清晨，她发现自己无法感知到「下尸神兹𫏋」的存在。与此同时，七七的敕令开始频繁出错，白术诊断后发现与兹白的三尸法产生了某种共鸣。玩家需要在兹白的记忆碎片和七七的敕令之间找到联系，而线索指向了一个不该存在的人——一个自称「琅玕遗民」的神秘人出现在璃月港。切入点：替白术守着七七、陪兹白走一遍旧地，或去查那个「琅玕遗民」。可能走向：仙箓失效的危机，与一份来自上古琅玕的旧约。
