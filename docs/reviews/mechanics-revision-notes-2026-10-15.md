# 物品、队伍与敌怪机制修订

本轮已直接修改有效设定、数值定稿和相关引擎。授权依据：用户要求检查不合理机制并进行机制/数值修改，允许减少敌种。未修改正式存档，未安装或启动 DSH。

## 一、问题与改动

| 原问题 | 本轮处理 | 原因 |
|---|---|---|
| 神像既写供奉养成又禁止供奉；传送随时可用 | 神像为全队每日一次短休，不与同次场景短休叠加；安全锚点只连接同站已知锚点 | 保留探索与连续冒险的资源压力 |
| 摩拉不记账，却要求强化消耗；采集离区刷新 | 共享补给 0–6 格、起始 3；关键材料与消耗品记数量，反复往返不刷新 | 轻量但可检查成本，避免无限资源 |
| 武器名字附赠攻击、暴击和生命，与五类数值重复 | 保留名称背景，统一按类型、实际品质与定稿套效计算；旧随机数值停用 | 避免换名字重复叠属性 |
| 一星遗物仍加 HP，强化先攻 +2 变 +5、权重可能归零 | 一星仅占位；仅 HP/伤害/减伤/反应固定值参与强化 | 小数与离散属性不适合伤害量化 |
| 拾摩拉、反复开箱可无限回血 | 幸运儿与冒险家按真实奖励触发，每场景一次；不重复触发同一来源 | 消除无限恢复循环；触发次数仍需显式记账 |
| 扎营没有回满能量，满血也报告理论治疗量 | 扎营/休整实际回能，返回实际 HP/能量变化 | 工具返回值与角色状态一致 |
| 玩家被写成旅行者，单人三人队超出既有输出假设 | 玩家与旅行者明确分离；单人玩家+旅行者，额外 NPC 为有限支援 | 保留人格与关系玩法，不免费增加战斗位 |
| 五级好感与四阶关系冲突，重复送礼刷阶 | 统一陌生/相识/信任/羁绊；保留旧名迁移规则，关键事件升级 | 对齐引擎并避免交涉购买忠诚 |
| 切换元素同时扣行动、首击减值、每日次数，又另有免费双攻击 | 已解锁元素切换只消耗整次行动；无共鸣点、每日次数和免费双攻击 | 减少计数负担，不侵占玩家角色输出 |
| 旧敌怪有上千行重复、百万 HP、秒数、成就与指定角色门槛 | 24 个运行模板：13 常规、8 首领、3 传奇，原稿完整归档 | 按战术差异保留敌种，减少无用维护 |
| 每只首领全额叠加、召唤物另加行动 | 每场最多 4 点/4 单位，首领独占预算；一次群攻权限，召唤物共用预算 | 控制的是整场压力，而不是仅限制单个敌人 |
| 杂兵伤害按 5 量化、首领超时自动追加阶段 | 伤害取整数；阶段共用 HP，按 50%/25% 阈值换招，超时结束整场 | 不抹平低伤害，不靠重置拖长战斗 |

## 二、数值依据

- 劲敌 HP 基数：50 → 40；多人首领：90×n → 70×n。群攻递增、单体递减、HP 随 n 线性增长的结构保留。
- 单人首领直接使用最终值 HP 110、群攻 18、单体 20，不重复缩放。n=1 不额外计算旅行者；旅行者 HP 由 120×0.8 向下取 5 得 95。
- 多人首领三人：210 HP、群攻 31、单体 18；四人：280 HP、群攻 34、单体 16。
- 36 种骰面精确枚举：修正 +3、基础武器伤害 25，无装备/反应，含失败与代价成功的平均输出为 18.5833/轮。按平均输出估算耗时：旧首领约 4.84 轮，新首领约 3.77 轮。
- 这是固定条件的节奏校核，不是真实随机击杀时间或实战平衡保证。玩家会改变武器、姿态、行动和反应，首领也会受控或因场景目标提前结束；需真实跑团继续调参。
- 无减伤、敌人每次攻击命中率 30/36 的参考：单人玩家武器权重 1.5、旅行者 1.2 时，预期受伤约 24.26/轮；四人平均约 31.67/轮。此数值也不是保证每轮固定扣血，不忽略仇恨差异给某个玩家强行均摊。

## 四、验证与实现边界

原有 45 项测试保留并按新裁定更新旧预期；新增 7 项敌怪回归、4 项物品回归，总计 56 项，最终实测全部通过、0 失败。覆盖名录与文档对应、历史首领不自动启用、预算拒绝、群攻权限、整数缩放、阶段不回血和超时、一星无加成、小属性强化、恢复实际值及回能。

工具处理函数额外验证：24 模板、按名开战、单人最终值、超预算拒绝、未知操作拒绝、round=4 时收场；在独立临时目录执行并清理。替代了 defineTool 注册，仅验证处理函数，不代表真实宿主 schema 或会话权限已验收。

下列部分仍需 GM 显式调用状态与数值工具：补给/库存扣除、每场景消耗次数、NPC 支援、旅行者切换、关系更新、护甲/核心/召唤/锚点互动、冻结生命周期。模板元数据不是自动技能执行器。

战斗和场景完整持久化、装备派生值自动回写、严格剧透过滤仍未完成。本轮修正了推进工具省略累计轮数时的默认行为，但未使调用方传入的轮次成为可信持久化状态；完整多阶段转换仍以引擎同一状态对象的执行为准。

下一步优先用“一次采集和补给 → 带 NPC 支援的剧情 → 一次机关首领 → 扎营 → 重启续接”的短战役验收这些规则，再决定是否继续添加敌种。
