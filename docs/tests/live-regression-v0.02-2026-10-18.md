# v0.02 实机回归记录（2026-10-18）

## 测试范围

使用既有 DSH 会话“原神单人跑团：蒙德风灾巡查”检查 v0.02 主持规范接入并继续一轮剧情；另用无战役的新会话验证工具运行时。未创建独立战役档或回档原有蒙德存档。

## 结果

1. 既有剧情中，玩家明确说“到入口听一次风，先不往里走”。GM把行动目标改成带温迪进入裂口，并为额外移动发起检定，构成行动范围越界。玩家指出后，GM承认越界、取消越界检定带来的线索，退回入口叙述。该样本不通过边界测试，但更正后的回应遵守了停止点。
2. 请求只读调用 `trpg_char` 的 `writing` 指引，实际工具返回 `guidance topic 须为 mainline/mondstadt/continuity`。组件开关与页面重载后，在原会话再次调用仍相同。
3. 新会话中按 `input:{op:"guidance",topic:"writing"}` 精确调用已有测试槽，仍返回相同旧主题列表。由此确认运行中的 DSH 插件执行代码未随页面或组件刷新更新。新会话最初因提示描述不够明确而构造了错误入参；工具说明现已补充完整 JSON 示例。
4. 首次错误探针初始化了 `compat_check` 空目录。检查确认目录内无文件、无事件日志，随即清理；没有创建可游玩的测试存档，也没有修改用户的既有战役。
5. DSH 完整重启后，使用 `trpg_char` 对既有测试槽 `first_test` 只读请求 `input:{op:"guidance",topic:"writing"}`，返回新版行动边界检查与关键交流自检全文；没有调用存档写入工具，也没有创建新槽。
6. 回到原有蒙德存档，玩家要求驻点休息、次日返城向琴汇报并询问城北调查，同时明确不接受新委托。GM按规则休整：第18日推进到第19日，补给1→0；安全返城未强制检定。琴提供有限的后续信息，旅行者和温迪各自回应，未替玩家选路线或接受委托。叙述停在两条可能线索之后，等待玩家行动。
