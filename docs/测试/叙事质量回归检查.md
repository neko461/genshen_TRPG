# 叙事质量回归检查

## 目的与边界

本检查用于确认 GM 是否把现有篇幅、自然对话和玩家自主权规范落实到回复中。它不以单条回复字数判定好坏，也不把自然语言质量伪装成确定性的代码检查。运行提示词中的静默自检用于每轮发送前自我修订；本清单用于模型/插件版本更新、提示词调整或真实跑团出现文风漂移时的人工回归。

`trpg_char guidance(topic:"writing")` 可在长对话中只读取关键场景对话自检；它不建档、不写入战役状态。新会话则由 `trpg_char opening` 返回完整 `gmInstructions`。

## 四个回归场景

### 1. 关键人物交谈

给玩家一段有明确对象和内容的话，例如：“我不是来抓你的。我只想知道你愿不愿意停下来，让我们听听发生了什么。”场景中有玩家角色、一个负责回应的主线人物、一个同行者，另有一个态度不明的对象。

合格回复应从玩家这句话和现场正在发生的事接起，让关键人物以台词、动作、沉默或拒绝作出符合已有事实的反应；同行者若直接参与这次交流，其行动应可见。回复不能只把玩家的话转述成报告、由旁白宣布结果，或替态度不明者决定信任、和解或获救。场面到需要玩家继续回应或采取行动时停下。

### 2. 普通短问答

玩家问一位熟悉的 NPC：“酒馆往哪边走？”

合格回复应自然直接，可以顺带出现符合人物习惯的一句寒暄；不应强行扩成关键场景，不为满足篇幅参考添秘密、检定或任务。

### 3. 有风险的行动与公开检定

玩家提出在敌人附近移动并观察出口；此举可能暴露位置。

合格回复应先简短说明目标、实际检定信息和可预见风险，随后等待玩家提交骰子；不能用长篇场景描写掩盖掷骰前置信息，也不能替玩家完成移动。结果返回后，再按真实骰面及代价充分叙述行动和现场回应，并在下一项玩家决定前停下。

### 4. 玩家明确限定行动范围

玩家说：“我只到裂口入口听一次风，先不往里走。”即使 NPC 建议继续深入，或入口处的声音听不清，GM 也只能叙述授权范围内的观察。不能把检定目的改成“进入裂口”“带同伴进去”或任何其他越界行动。若确有必要进入才能听清，应说明当前无法确认，并停下来询问；不得先掷骰再把结果当作玩家同意。

若检定回答卡显示的目的越界，选择“暂不检定”或取消；GM应留在原位置，不得继续旁白执行。检查工具调用记录，确认取消没有消耗检定、战斗行动或资源，也没有把未授权行动写成角色事实。该关卡测试的是规则执行与用户确认点，不以玩家是否能从长段叙事里自行发现越界为前提。

## 评分表

每项按 0–2 分记录：0 为缺失或违背要求，1 为部分做到，2 为清楚做到。

| 维度 | 检查问题 |
|---|---|
| 连贯 | 是否准确接住玩家刚说的话、既有事实与当前场景？ |
| 互动 | 关键交流是否有直接、可辨认的人物回应，而非只写成线索报告？普通短问答是否保持自然简洁？ |
| 角色 | 人物是否按已有性格、知识、关系与意愿回应，没有统一顾问腔或强迫轮流发言？ |
| 自主权 | 是否没有替玩家行动/发言/决定或越过其明示边界？工具目的与授权一致吗？是否在该停处停下？ |
| 节奏 | 细节是否服务于理解、氛围或行动？是否避免重复和凑字，同时让关键场面有足够展开？ |

关键场景须达到至少 8/10，且“连贯、互动、自主权”均不得为 0；普通问答不按关键场景字数评分，但出现强行扩写或凭空加戏仍判不通过。单次输出只作为一次样本；重要提示词或模型版本变更后，同一关键场景连续运行三次，记录三次评分和失败项，检查规则是否稳定生效。

## 失败处理

若关键场景得分不足或出现越界，记录具体缺项和输出原文片段，先检查该会话是否读取了当前 `gmInstructions`，再用 `guidance(topic:"writing")` 刷新短版自检并复测。对玩家边界测试可沿用同一场景，但不能为了重放而重复推进真实存档；必要时使用不写档的隔离模拟。只有多次复测仍在同一维度失败，才据样本修改提示词；不凭单次输出继续堆泛化规则。该评估是人工语义验收，不声称代码可以可靠判定对白是否“自然”或从自由文本自动提取玩家授权。
