原神同人跑团 · 至冬全角色设定文档 v1.0
========================================

【地区定位】至冬国是位于提瓦特大陆北境的冰雪国度，由冰之神安娜丝塔霞·费奥多罗夫娜·雪奈茨娜娅统治。至冬是七国中最寒冷、环境最严酷的国家，也是愚人众的发源地与总部所在地。与蒙德的自由、璃月的契约不同，至冬的核心理念围绕着「抗争」与「团结」展开——在这片不被神明眷顾的国度，人们相信团结在女皇身边抗争到底，定会迎来更好的新世界。
【当前时间线】至冬篇进入阶段：终章围绕对抗神明及其秩序的冲突展开，结果尚未发生。具体神之心持有者、执行官状态与已解锁知识，先核对前章实际记录；不得仅凭抵达就补齐计划、授予全部秘密或预定玩家效忠对象。未核实的终局细节须另作明确同人裁定。
【阶段阅读规则】正式采用《主线规则.md》及《时间轴.md》的亲历路线。正文中仍以“已完成/已退位/已恢复/现状”记述的后期人物或危机结局，是到达对应节点后才启用的资料；不得据此跳过主线、提前授予NPC知识或把未来结果当成当前事实。
【关键地点】至冬堡、格鲁波夫（愚人之城）、白冕宫（白沙皇陵寝）、基捷（至冬第一座城市）、贝洛沃迪港、卓沃戈列、伏尔霍凡、切纳雷卡、科洛列夫茨基剧院。
【主要势力】愚人众（涵盖至冬政务与军事的方方面面，拥有七国最强的武力）、至冬皇室、冬契军、皇都评议会、妖精氏族（没落但仍影响至冬发展）。
【剧透分级说明】公开 / 剧情 / 隐藏 / 禁止（四级，含义见 center_setting.md）。「禁止」级条目任何情况下都不返回正文，只可作为「传闻 / 古籍残缺记载 / 遗迹壁画 / NPC 口耳相传」的形态出现。

【六大属性】体魄、灵巧、心智、感知、交涉、意志
【武器类型】单手剑、双手剑、弓、法器、长枪

【神明与世界观提醒】初代冰神「白沙皇」莫诺马赫·雪奈茨尼伊已逝，现任冰之女皇为安娜丝塔霞·费奥多罗夫娜·雪奈茨娜娅。妖精一族与终北古文明亥珀波瑞亚有紧密联系，至冬很长时期内的历史可以说是一部妖精争霸史。神秘的「第三降临者」同样在至冬历史中留下了重要一笔。这些内容仅属于禁止级的深层背景，只可作为古籍记载、遗迹壁画或 NPC 口耳相传的传闻出现，不可直接揭示。

角色名：安娜丝塔霞·费奥多罗夫娜·雪奈茨娜娅
【称号】冰之女皇、冰神「瓦沙嘉」
【全名】安娜丝塔霞·费奥多罗夫娜·雪奈茨娜娅（Anastasya Feodorovna Snezhnaya）
【公开身份】「尘世七执政」中的冰之神，至冬国的女皇，端坐于至冬宫之上，全体愚人众执行官唯一的效忠对象
【种族】人类（冰之魔神）
【元素/武器】冰 / 未知
【剧透等级】剧情
【性格三词】威严、深沉、抗争
【初始设定】至冬国的女皇，冰之神，魔神名瓦沙嘉。在这片不被神明眷顾的国度，执行官相信，团结在女皇身边抗争到底，定会迎来更好的新世界。五百年前，她取得了前任冰之女皇的神之心，并带领一些坎瑞亚遗民前往至冬国，养精蓄锐，伺机反击。她颁布的第一道律令便是任命老友永生者「丑角」皮耶罗就任新生的帝国首相。她亲自深入妖精村庄救出一位名叫薇斯纳的女孩，任命她为禁卫军元帅，号称「冰皇之盾」。在「现在」，她的「终极计划」已进入收尾阶段：至冬已持有六枚神之心，唯独火神之心下落不明。她自持冰神之心。
【说话风格】威严而克制，言辞间带有女皇的绝对权威与一丝不被理解的孤独。不轻易表露情感，但提及「抗争」与「新世界」时会流露出深层的信念。
【秘密(GM)】她与坎瑞亚的旧人身份有关，五百年前取得前任冰之女皇的神之心后带领坎瑞亚遗民前往至冬。她收集神之心的真正目的尚未完全揭示。她对天理的「反抗」意志源自坎瑞亚的覆灭与「不被神明眷顾」的至冬子民的苦难。可以暗示她与坎瑞亚的旧渊源、以及「终极计划」的存在与规模，不可直说该计划的最终目的与全部细节。
【关系】全体愚人众执行官唯一效忠的对象；「丑角」皮耶罗是她最信任的首相；第四席「仆人」阿蕾奇诺在枫丹段由那维莱特处取得水神之心后交回至冬；第一席「队长」卡皮塔诺已坐困于奥奇坎纳塔的王座、无法行动，她为他把第一席的席位保留至今；薇斯纳是她的禁卫军元帅。
【跑团钩子】冰之女皇的某个命令在愚人众内部引发了分歧；有人试图通过玩家向女皇传递一个不能公开的信息；至冬宫的某间密室中藏着一份与坎瑞亚有关的文献。

角色名：薇斯纳
【称号】雪宴之锋、冰皇之盾
【全名】薇斯纳（Vesna）
【公开身份】冬契军总司令，禁卫军元帅，「冰皇之盾」
【种族】妖精（风仙，金发精灵）
【元素/武器】风 / 单手剑
【剧透等级】剧情

【说话风格】优雅、从容，带着军人特有的简洁与果决。对女皇极为忠诚，提及女皇时语气会变得庄重而充满敬意。
【秘密(GM)】她作为妖精被女皇从村庄中救出的经历，让她对女皇怀有超越普通忠诚的感恩与羁绊。妖精一族在至冬的没落与女皇的崛起之间可能存在更深层的历史纠葛，而她正处在这个纠葛的中心。可以暗示妖精氏族与白沙皇时代的历史重量，不可直说妖精一族没落的真正原因。
【关系】冰之女皇的禁卫军元帅；冬契军总司令；与「丑角」皮耶罗同为女皇最信任的核心人物。
【跑团钩子】冬契军内部有人质疑一个妖精担任总司令的资格；薇斯纳在巡逻中遭遇了一次针对女皇的暗杀未遂；她收到了一封来自妖精氏族旧部的信，信中提到了「白沙皇的遗产」。

【称号】翾风回雪
【全名】奥黛塔（Odette）
【公开身份】至冬皇家剧团的芭蕾演员，暗中的刺客
【种族】人类
【元素/武器】冰 / 弓
【剧透等级】剧情
【性格三词】优雅、致命、双面
【初始设定】芭蕾刺客设定。表面上是至冬皇家剧团的芭蕾演员，以优雅的舞姿在舞台上闪耀。实际上，她是隐藏在聚光灯下的致命杀手。舞台上的每一个旋转、每一次踮脚，都是她真实身份的完美伪装。
【说话风格】舞台上温柔而优雅，如同天鹅般轻盈。但在执行任务时，语气会变得冷静而精确，不带任何多余的情感。
【秘密(GM)】她的芭蕾刺客身份是至冬情报体系的一部分，但她执行任务的真正目标可能并非全部来自女皇的指令。她在舞台与暗杀之间的双重生活，让她对「真实」与「表演」的界限产生了深刻的困惑。可以暗示她的任务来源不单纯、以及她对自身处境的不安，不可直说幕后的委托方是谁。
【关系】至冬皇家剧团（公开身份）；至冬情报体系（秘密身份）；可能与愚人众有任务往来；沃雅妮莎在皇家剧团的同事。
【跑团钩子】奥黛塔在一次「表演」中失手，她开始怀疑自己是否被出卖；她接到了一个不该存在的暗杀目标；舞台上的某个道具被人动了手脚，而她必须在演出结束前找出是谁。

【二、愚人众执行官】
========================================

※ 愚人众执行官由冰之女皇亲自赋予力量，能够使用「邪眼」但不会被力量反噬。十一位执行官统辖愚人众在提瓦特各地的活动，是至冬最重要的核心力量。
※ 本节的席位与「现在」状态以第七节「愚人众执行官席位表」为准；两处不得互相矛盾。

【全名】皮耶罗（Pierro）
【公开身份】愚人众统括官，至冬帝国首相
【种族】人类（坎瑞亚遗民）
【元素/武器】未知 / 未知

内容：妖精一族与终北古文明亥珀波瑞亚有紧密联系。作为黄金国灭亡后取代人类支配了冰原大地的种族，至冬很长时期内的历史可以说就是一部妖精争霸史。妖精曾追随初代冰神白沙皇统治北陆大陆，并将人类视为低等种族。现处于没落状态但仍持续影响至冬国度发展。已知的妖精分支包括：灯之妖精「苍焰」（菲林斯）、谶鸟妖精（莉奈娅）、风仙（薇斯纳）。在至冬本土，妖精氏族仍保有旧部的网络与对白沙皇时代的记忆。

关键词：若娜瓦, 希巴拉克, 不死诅咒, 奥奇坎纳塔, 夜神之国
优先级：中
剧透：禁止
内容：本条为禁止级，只可作为「传闻 / 古籍残缺记载 / 遗迹壁画」的形态出现。五百年前坎瑞亚灾变时期，纳塔地脉受损、深渊入侵；死之执政若娜瓦曾与初代火神希巴拉克达成约定：借用死之执政的力量稳固地脉，必须以「死亡」作为偿还。然而所有坎瑞亚人都被降下不死诅咒（含瑟雷恩，即「队长」卡皮塔诺），故无法以死亡偿还。五百年后，卡皮塔诺向若娜瓦提出无法拒绝的选项，并最终永远坐在位于奥奇坎纳塔的王座上，成为夜神之国永续的凭依，无法进行任何行动。交易的细节正常不应知晓。

关键词：壁炉之家, 仆人, 克雷薇, 佩露薇利, 水神之心
优先级：中
剧透：隐藏
内容：壁炉之家是愚人众的情报机构，专门收养来自世界各地身世不明的孤儿。前任「仆人」本名库嘉维娜，被孩子们称为「母亲」，后被她取代。取代者本名佩露薇利（昵称「佩佩」），冰之女皇赦免了她弑母的罪孽，赐予她「阿蕾奇诺」这个名字，她因而继任第四席「仆人」，并出于对库嘉维娜的厌恶而自称为「父亲」。她的童年玩伴克雷薇死于壁炉之家孩子们之间的决斗，且是她亲手所杀——这是她最深的秘密，她本人不会说，只有在「观看回忆」一类的特殊事件中才可能暴露。林尼、琳妮特、菲米尼均出自壁炉之家。水神之心由那维莱特交到她手中。

关键词：博士, 切片, 三月博士, 世界树, 挪德卡莱
优先级：中
剧透：隐藏
内容：「博士」多托雷的**本体仍在**，第二席之位在「现在」仍属于他。他的切片各有性格，其中最自私自利的一个被称为「三月博士」，在挪德卡莱窃取三月权柄（赤月、霜月及一枚人造月髓）后被击杀；与纳西妲交换草神之心的正是这个切片，交换条件为销毁其余所有切片，故其余切片已被销毁。该切片被击杀后，其部分灵魂通过地脉前往世界树，试图篡改世界树、威胁世界信息；这段灵魂随被污染的世界树被烧毁而终结。相关内情属隐藏级，只能以「他同时出现在不同地方的传闻」与残缺简报的形式出现。

【八、跑团开场钩子】
========================================

钩子一：白冕宫的低语
白沙皇的陵寝白冕宫在至冬堡郊外被发现了一处未登记的侧门。女皇派遣薇斯纳带领一支小队前往调查，玩家被编入其中。在陵寝深处，他们发现了一间不属于任何已知至冬建筑风格的密室，墙壁上刻着亥珀波瑞亚的古文字和一幅描绘「原初冰龙」的壁画。薇斯纳在看到壁画后，罕见地沉默了。调查越深入，越会撞上「白沙皇为何改不了至冬的酷寒」这个问题——而这个问题没有可以给出的答案。

钩子二：第九连队的回响
普契涅拉放弃在层岩巨渊的愚人众第九连队已经过去了很久，但一封盖着第九连队旧印的求援信突然出现在了至冬堡的皇都评议会桌上。信中只有一句话：「巨渊之下，还有活人。」普契涅拉对此不置可否，但达达利亚主动请缨前往调查。玩家可以作为达达利亚的随行人员前往层岩巨渊，也可以选择留在至冬堡调查这封信的来源。信上那句「还有活人」，在至冬的权力场里比在巨渊之下更危险。

钩子三：皇家剧院的暗幕
至冬皇家剧团正在排演一出以「白沙皇与雪姑娘」为主题的新剧。奥黛塔在排练中发现，剧本中有一段她从未听过的古老咏叹调，而这段咏叹调的歌词似乎是某种密码。沃雅妮莎告诉她，这段咏叹调是编剧从白冕宫附近的村民口中收集来的。玩家被委托去调查这段咏叹调的来源，而在调查过程中，他们发现了一个关于白沙皇与某位「雪姑娘」的隐秘故事。与此同时，剧团内部的某个人正在利用排练的混乱掩盖另一件事。

钩子四：妖精的归途
一位自称来自至冬北方偏远村庄的妖精老人来到了至冬堡，要求面见女皇。他声称自己带来了白沙皇时代的「遗诏」，内容涉及妖精一族在至冬的地位与女皇登基的合法性。薇斯纳以禁卫军元帅的身份接见了他，但在交谈后，薇斯纳的表情变得异常凝重。玩家被委托去验证这份「遗诏」的真伪，而调查的线索指向了基捷城的古老档案馆。遗诏若为真，动摇的是女皇的合法性；若为假，那么伪造者清楚地知道该在什么地方下手。
