【地区定位】雷元素的国度，信奉「永恒」。稻妻幕府为最高统治机构，雷电将军为最高主宰；三奉行（社奉行、天领奉行、勘定奉行）分管政务、治安与财政。海祇岛为独立势力，信奉珊瑚宫。进入本章时锁国令与眼狩令仍在实施。
【当前时间线】稻妻篇进入阶段：锁国令与眼狩令仍在施行并影响民众，奉行与反抗力量的冲突未解决。雷电将军公开治理，雷电影的一心净土及其真相仍受知情限制；雷神之心移交、废令和三奉行改革须在对应事件后发生。神樱大祓不默认完成。
【阶段阅读规则】正式采用《主线规则.md》及《时间轴.md》的亲历路线。正文中仍以“已完成/已退位/已恢复/现状”记述的后期人物或危机结局，是到达对应节点后才启用的资料；不得据此跳过主线、提前授予NPC知识或把未来结果当成当前事实。
【关键地点】稻妻城、天守阁、鸣神大社、海祇岛、珊瑚宫、渊下宫、神里屋敷、长野原烟花店、八重堂、离岛、鹤观。
【主要势力】稻妻幕府（社奉行、天领奉行、勘定奉行）、鸣神大社、海祇岛·珊瑚宫、终末番、荒泷派、狛荷屋、长野原烟花店、愚人众（在稻妻转入地下活动）。
【剧透分级说明】公开 / 剧情 / 隐藏 / 禁止（四级，含义见 center_setting.md）

【六大属性】体魄、灵巧、心智、感知、交涉、意志
【武器类型】单手剑、双手剑、弓、法器、长枪

【一、鸣神岛·雷电将军与鸣神大社】
========================================

角色名：雷电将军（雷电影）
【称号】一心净土、御建鸣神主尊大御所大人
【全名】雷电影（Raiden Ei／魔神名「巴尔泽布」）
【公开身份】稻妻幕府最高主宰，雷电将军
【真实身份】雷神巴尔泽布（GM 隐藏）
【种族】人偶（雷电影所造）／魔神（雷电影，位于一心净土）
【元素/武器】雷 / 长枪
【剧透等级】剧情
【性格三词】威严、内敛、矛盾
【初始设定】此世最殊胜威怖的雷霆化身。真名为「雷电影」，初代雷神巴尔的妹妹兼影武者。真去世后，影创造人偶「将军」代为治国，自身在「一心净土」中冥想。追求「永恒」，曾因失去太多而恐惧变化。如今对永恒的追求有所松动，三奉行改革得以推进，但性格仍内敛寡言。作为雷电将军时，她以绝对威严与公事公办的姿态处理稻妻政务，对臣下极少流露私情。
【说话风格】威严、简洁、偶尔流露对过去的感伤。提到甜食时会短暂放松。人偶形态下言辞更冷硬、程式化，偶有「判断」「结论」式的机械用词。
【秘密(GM)】稻妻城中的雷电将军是人偶，雷电影本体在「一心净土」中冥想；人偶将军已开始出现「自我意识」的苗头。她曾与真共同赢下魔神战争，真在坎瑞亚灾变中陨落，这是她追求「永恒」的根源。神之心曾交由八重神子保管，此后由八重神子交给愚人众（详见第七节「雷神之心的去向」），影本人已不再持有雷神之心。可暗示：人偶与本体并非一人、影对「永恒」的动摇、她与真之间的丧失之痛；不可直说：不可直接告知玩家「将军是人偶」「真已陨落于坎瑞亚」以及神之心移交的完整链条，须由剧情推进、一心净土入口开放或八重神子开口后揭示。
【关系】八重神子是眷属与挚友；九条裟罗是笃信者；神里兄妹是臣下；与珊瑚宫心海、海祇岛有复杂的历史渊源；人偶将军与雷电影本体互为「造物与造主」。
【跑团钩子】一心净土的异常波动；人偶将军开始出现「自我意识」的苗头；坎瑞亚灾变的真相可能动摇影的信念；三奉行改革触动旧族利益，有人试图借将军之名清洗政敌。

角色名：八重神子
【称号】浮世笑百姿
【全名】八重神子（Yae Miko）
【公开身份】鸣神大社宫司，八重堂总编
【真实身份】狐之血脉的妖怪，雷电将军的眷属（GM 隐藏）
【种族】狐之血脉（妖怪）
【元素/武器】雷 / 法器
【剧透等级】剧情
【性格三词】狡黠、优雅、深情
【初始设定】掌管鸣神大社的大巫女、狐之血脉的延续者、「永恒」的眷属与友人，以及轻小说出版社「八重堂」的恐怖总编。有着多重身份的神秘宫司，凡人或许永远无法了解她的真面目与真心。在先代雷电真时期就是雷神的眷属，雷电真陨落后成为雷电影唯一可以交心的挚友。神樱大祓由她与旅行者一行人共同了结，此后仍以宫司身份守护鸣神岛的地脉。
【说话风格】慵懒、带调侃、话中有话。喜欢捉弄人，尤其是旅行者和影。催稿时会忽然变得极有压迫感。
【秘密(GM)】她曾保管雷神的神之心，后来将其交给愚人众。当时的完整背景是：她与愚人众达成这笔交易时，散兵本人就是愚人众执行官，神之心随他而至——也就是说，雷神之心从此离开稻妻，落入愚人众体系。此后发生的事她并不知情：须弥大贤者使用雷神之心试图创造人造魔神（险些成功）；其后纳西妲将雷、草两枚神之心一并交给博士。八重神子只知道「自己交出了神之心」这一件事，不知道它最终流向何处、被用来做过什么。她也不太认同雷电影追求的「永恒」。对轻小说有狂热爱好，会催稿。可暗示：她「做过一笔不愿提起的交易」、她对愚人众的态度里有心虚也有算计、她刻意回避「神之心的下落」这个话题；不可直说：不可由她口中说出雷神之心的完整移交链（她确实不知道后续），也不可由旁白直接向玩家倾泻这条链条——链条只在第七节世界书中对 GM 开放。
【关系】雷电影的眷属与挚友；与九条裟罗有工作往来；经常使唤早柚；与梦见月瑞希可能有旧交；对旅行者既是委托人也是试探者。
【跑团钩子】神樱大祓后地脉仍有隐患；八重堂收到了一份不该存在的小说原稿；神之心的旧交易可能被愚人众当作要挟的筹码；她手中「另一件事」的真相只有旅行者记得（见第六节散兵条目）。

【二、社奉行·神里家】
========================================

角色名：神里绫华
【称号】白鹭霜华、白鹭公主
【全名】神里绫华（Kamisato Ayaka）
【公开身份】社奉行神里家大小姐
【元素/武器】冰 / 单手剑
【种族】人类
【剧透等级】公开
【性格三词】端庄、聪慧、温柔
【初始设定】稻妻「社奉行」神里家的大小姐。容姿端丽，品行高洁。贵为「公主」，平日主理家族内外事宜。常出现在社交场合，与民间交集较多，被雅称为「白鹭公主」。尽管作为雷电将军的臣下，但对眼狩令不满，曾暗地里协助神之眼持有者。锁国令与眼狩令废除后，她更多以社奉行的名义参与民间事务，是三奉行改革中较为开放的一翼。
【说话风格】端庄、得体、真诚。对亲近的人会流露少女心。
【秘密(GM)】曾暗中协助反抗眼狩令的人。对旅行者有特殊感情，但深藏心底。母亲早逝，父亲重病后与兄长共同撑起家族。可暗示：她谈及眼狩令旧事时的停顿、她对旅行者的在意、神里家昔日的窘迫；不可直说：不可直接说出她曾协助反抗者——须由具体证物（旧信、藏匿的神之眼、被救者的口述）触发。
【关系】神里绫人的妹妹；托马是她最信任的家臣；与宵宫有私交；在民间声望极高，与勘定奉行的旧族关系微妙。
【跑团钩子】神里家收到一封来自枫原家的旧信；绫华在民间巡查时发现了被藏匿的神之眼；她与宵宫的私交可能被有心人利用。

角色名：神里绫人
【称号】磐祭叶守
【全名】神里绫人（Kamisato Ayato）
【公开身份】社奉行神里家现任家主
【元素/武器】水 / 单手剑
【种族】人类
【剧透等级】剧情
【性格三词】温和、腹黑、掌控
【初始设定】身为三奉行之一——社奉行神里家的家主，神里绫人的名号在稻妻可谓无人不知。总有办法以周全的手段实现自身目的。不过，鲜少有人知道他如今最在意的「目的」是什么。早在前任社奉行病倒、神里家摇摇欲坠之时，正是年轻的他稳住了局势。三奉行改革推进之际，他是幕府内部最擅长以文书与人事达成目的的人。
【说话风格】温和、得体、话中带刺。很少直接表露真实想法。习惯用「不如」「也好」这类留有余地的措辞把选择权交给对方。
【秘密(GM)】暗中布局维持稻妻稳定，手段远超表面。与终末番有深层联系。对妹妹绫华的保护欲极强，会暗中清除任何威胁。可暗示：终末番与社奉行之间存在看不见的线、他对某些「意外」早有预知；不可直说：不可直接说出他下令清除过谁——须由档案、委托记录或早柚的只言片语间接暴露。
【关系】神里绫华的兄长；托马是他的家臣；与九条裟罗有政务往来；通过终末番调度早柚；对八重神子既倚重又防备。
【跑团钩子】终末番接到了不应存在的暗杀委托；绫人在暗中调查某个与神里家旧事有关的组织；他的「目的」可能牵涉到前任社奉行的死因。

角色名：托马
【称号】渡来介者
【全名】托马（Thoma）
【公开身份】社奉行神里家家政官，稻妻「地头蛇」
【元素/武器】火 / 长枪
【种族】人类（蒙德出身）
【剧透等级】公开
【性格三词】热情、可靠、外来者
【初始设定】蒙德出身的托马现居稻妻，他既是社奉行神里家的家政官，也是活跃在稻妻的「地头蛇」。为人友善又富有亲和力，不论身处何处都能轻易融入人群。乍看似乎是个非常随性的人，实际上却很有责任感。作为外国人，他曾是眼狩令的直接受害者，如今这段经历反而成了他在稻妻街头人脉的来源。
【说话风格】热情、直接、带蒙德口音的稻妻话。喜欢用「朋友」称呼别人。
【秘密(GM)】父亲是稻妻人，母亲是蒙德人。因为是外国人，在稻妻曾受到排斥，但凭借社交能力站稳了脚跟。对神里家极忠诚。可暗示：他在稻妻街头「什么都知道一点」、他与蒙德之间有未断的联系；不可直说：不可直接把他的血统说成政治把柄——须由户籍文书、旧案卷宗或来自蒙德的信件揭示。
【关系】神里兄妹的家臣；与宵宫关系良好；在稻妻城有广泛的人脉；与离岛的外国商人有往来。
【跑团钩子】托马的人脉网中有人向愚人众泄露消息；一封来自蒙德的信让他陷入两难；他暗中帮助过被眼狩令迫害的人，旧事可能被翻出。

角色名：早柚
【称号】忍里之貉
【全名】早柚（Sayu）
【公开身份】隶属于「终末番」的特别忍者
【元素/武器】风 / 双手剑
【种族】人类
【剧透等级】公开
【性格三词】懒散、可爱、逃避
【初始设定】隶属于秘密组织「终末番」的特别忍者，对睡眠和长高有着异乎常人的追求。掌握一切可用于逃跑、隐蔽的忍术，以此为自己创造偷懒睡觉的机会。自幼在终末番长大，对组织有极高的忠诚度。是忍术流派「呜呼流」最后一代传人。
【说话风格】有气无力、经常打哈欠、提到长高时会突然认真。
【秘密(GM)】终末番是隶属于社奉行的秘密组织。早柚停止长高已经很久了，久到她觉得自己落入了一个时间停止的梦。终末番的某些任务可能涉及稻妻的黑暗面。可暗示：终末番的委托内容从不见光、她对自己的身形有说不出的执念；不可直说：不可直接说出终末番的暗杀与监视职能——须由她无意间说漏的任务代号、或绫人交办的事务暴露。
【关系】神里绫人是指挥者；被八重神子使唤；与鹿野院平藏有工作交集。
【跑团钩子】一次偷懒时意外撞见愚人众的密谈；终末番接到了一份来自「已死之人」的委托；呜呼流的秘术可能被外人觊觎。

【三、天领奉行】
========================================

角色名：九条裟罗
【称号】黑羽鸣镝
【全名】九条裟罗（Kujou Sara）
【公开身份】天领奉行大将
【元素/武器】雷 / 弓
【种族】人类（天狗血统）
【剧透等级】公开
【性格三词】忠诚、严肃、正直
【初始设定】天领奉行九条家的养女，幕府军的大将。九条裟罗有着天狗血统，却不像一般天狗那样栖居于山林间。她自幼被九条家收养，归入天领奉行麾下。行如风，言如誓，是位魄力过人的女性。她有着「神的笃信者」之名，将全部忠心都奉献给了雷电将军。将军所追求的「永恒」，也是她愿意为之而战的信念。改革推进后，她开始学着把「忠诚于将军」与「忠诚于稻妻」分开思考。
【说话风格】简洁、直接、军事化。极少废话。对将军与天领奉行的称谓极为正式。
【秘密(GM)】天狗血统让她在稻妻有一定特殊地位。对眼狩令的执行曾让她内心挣扎，但最终选择了忠诚。私下有写和歌的爱好。可暗示：她写和歌的习惯、她在军令与良心之间的微妙迟疑；不可直说：不可直接说出她的天狗血统来源与九条家收养的内情——须由天领奉行的秘密档案、旧家谱或她的旧物揭示。
【关系】雷电将军的笃信者；与神里绫人有政务往来；与鹿野院平藏同属天领奉行；对九条家有知遇之恩的复杂感情。
【跑团钩子】天领奉行内部有人利用裟罗的忠诚设局；一封匿名信揭露了九条家收养她的真相；天狗血统可能被愚人众盯上。

角色名：鹿野院平藏
【称号】心朝乂安
【全名】鹿野院平藏（Shikanoin Heizou）
【公开身份】天领奉行天才少年侦探
【元素/武器】风 / 法器
【种族】人类
【剧透等级】公开
【性格三词】聪明、随性、洞察
【初始设定】天领奉行的天才少年侦探，直觉敏锐，心思巧妙。无论面对何种悬案，都能用出人意料的方式揭开真相。为人随性，不拘泥于规则，但心中有自己的正义标准。他不喜欢写报告，却总能把最棘手的三奉行旧案翻出水面。
【说话风格】随性、带点玩世不恭、推理时会突然变得犀利。
【秘密(GM)】年纪轻轻就成为天领奉行的核心侦探，背后可能有不为人知的经历。他的直觉有时候准得不像是直觉。可暗示：他「看穿一切」的能力来源不明、他手里压着几份不该存在的档案；不可直说：不可直接把他的直觉解释为某种超常能力——须由他在特定案件中的异常表现逐步累积。
【关系】天领奉行同僚；与早柚有工作交集；与九条裟罗共事；可能认识很多稻妻的地下情报贩子。
【跑团钩子】一桩看似普通的失窃案牵出了稻妻高层的秘密；平藏发现了一个「不该存在」的人；他的过去可能在某次调查中被揭开。

【种族】人类（现人神巫女，珊瑚宫血脉）

内容：稻妻是雷元素的群岛国度，幕府与三奉行影响日常生活，海祇岛有自己的立场。进入本章时锁国令与眼狩令仍在施行，离岛入境、民众处境与地区冲突需在剧情中了解。废令、改革、神之心移交及神樱大祓不默认完成；角色所知以亲历、来源与当前阶段为准。

关键词：海祇岛, 珊瑚宫, 渊下宫, 奥罗巴斯
优先级：中
剧透：剧情
内容：海祇岛位于稻妻西部，住民曾生活在海底的渊下宫。魔神奥罗巴斯将他们带到地面，才有了海祇岛如今的文明。奥罗巴斯被雷神斩杀后，身体化作枯骨，怨念凝成祟神气息。珊瑚宫心海作为现人神巫女，与珊瑚宫血脉有深层关联，须定期亲自确认渊下宫封印的状态。海祇岛与鸣神岛历史上存在信仰冲突，现已缓和。海祇军大将五郎身负犬妖血脉，被将士称为「常胜的尖耳将军」。渊下宫器物偶尔会随异常潮汐浮上海岸。

关键词：雷电五传, 一心传, 枫原家, 国崩
优先级：中
剧透：剧情
内容：「雷电五传」曾是稻妻最顶尖的五个锻刀流派，包括枫原家的「一心传」。数百年前，雷电五传遭「国崩」报复而受灭顶之灾，五传传至万叶一代仅剩「天目传」和「一心传」存世。此处的「国崩」**即散兵**（「散兵」本身是愚人众的代号，两者指同一个人）。枫原万叶是枫原家末代子弟，友人因眼狩令发起御前决斗被斩杀，万叶夺走友人的神之眼后逃离稻妻，如今栖身璃月「南十字」船队，友人的神之眼仍在他身上。该案的记载在稻妻档案中多处残缺——原因见下一条。

关键词：国崩与散兵, 愚人众第六席, 世界树, 降临者
优先级：高
剧透：隐藏
内容：「国崩」是散兵在稻妻时期的代号；「散兵」本身也是愚人众的代号，两者是同一个人。须弥段之后，散兵为挽回自己犯下的错，**修改了世界树，删除了自身犯下的错**。其结果有三层：其一，在**普通人视角中，愚人众第六席处于空缺状态**；其二，**他自己也不记得**；其三，**旅行者属于降临者，地脉无权修改其记忆，所以旅行者记得**。旅行者将此事告知纳西妲，再由纳西妲转告他。此后他的代号为「**流浪者**」，**玩家可赋予其名字**。另需注意：**散兵不属于魔神**；他体内的神之心其实是稻妻的雷神之心。稻妻段（第3站）不得套用须弥之后的记忆变化；相关后果须待对应世界树事件真实发生后启用。

关键词：雷神之心, 神之心去向, 八重神子, 造神计划
优先级：高
剧透：剧情
内容：雷神之心的完整移交链：**八重神子把雷神之心交给愚人众**（此时散兵本人就是愚人众执行官，神之心随他而至）→ **须弥大贤者使用雷神之心试图创造人造魔神，险些成功** → **纳西妲将雷、草两枚神之心一并交给博士**。此链为本章及须弥章后续事件资料，须在实际移交和废令之后才启用；稻妻进入状态不得套用这些结局。需要特别留意知情范围：**八重神子并不知道后续这些细节，她只知道自己交出了神之心**——她不知道须弥的造神尝试，也不知道两枚神之心最终交给了博士。因此该链条不可由她的口中说出，只可作为 GM 层面的因果依据。

【八、跑团开场钩子】
========================================

钩子一：神樱的低语
鸣神大社的神樱树在非祭典时期突然开花，花瓣飘落之处浮现出不应存在的「记忆残影」。八重神子委托玩家调查，而她在委托时罕见地收起了所有玩笑，只留下一句「有些东西，看见了也要当作没看见」。涉及角色：八重神子、旅行者、鸣神大社巫女（久岐忍可作引路人）。玩家的切入点是接下这份名义上「清扫落樱」的委托，逐片回收并记录残影内容。可能走向：残影指向神樱大祓未净的地脉深处，也可牵出「雷电五传」的旧案；若玩家把残影中那张面孔描述给八重神子，她会立刻转移话题——她只知道那一笔交易，不知道后来的事。

钩子二：海祇岛的异常潮汐
海祇岛沿岸出现异常潮汐，退潮后沙滩上浮现出不属于这个时代的渊下宫器物。珊瑚宫心海在冥想中看到了奥罗巴斯的残影，她需要玩家前往渊下宫入口处确认封印状态，五郎会随行护卫。玩家的切入点是作为外来的冒险家接受现人神巫女的委托，负责在封印外围取样与记录。可能走向：封印外侧有被人为撬动过的痕迹；器物上刻着与稻妻本土不同的文字；若玩家把器物带回鸣神岛，会引来不该出现的关注者；五郎的犬妖血脉可能在渊下宫深处产生异常反应。

钩子三：荒泷派的「正经委托」
久岐忍罕见地以「正经」身份发布了一份委托：荒泷一斗在鬼族旧地发现了一块刻有古老文字的岩石，文字的内容让一斗沉默了一整天。久岐忍希望玩家能帮忙解读，同时确保一斗不会做出什么冲动的事。涉及角色：荒泷一斗、久岐忍、鬼族旧地的知情老人。玩家的切入点是接下这份「翻译碑文」的委托，并与荒泷派一同前往旧地。可能走向：碑文记载的是鬼族被迫害的旧事，也可能指向某个仍在运作的旧组织；一斗可能因碑文做出冲动的举动；久岐忍会借此机会回避关于自己巫女出身的追问。

钩子四：天领奉行的秘密档案
鹿野院平藏在调查一桩失窃案时，意外发现了一份被标记为「已销毁」的档案。档案记载了九条家收养裟罗的细节，其中有一页被人为撕去——撕痕与「雷电五传」旧案卷宗的缺失页一致。平藏将此事告知玩家，但他不确定应该继续调查，还是把档案放回原处。涉及角色：鹿野院平藏、九条裟罗、天领奉行内部的相关者。玩家的切入点是协助平藏追踪失窃案的另一条线索。可能走向：继续追查会动摇九条家与裟罗的信任；中止追查则会让那一页永远消失；而那一页上写的名字，可能与一个所有人都已不记得的存在有关。
