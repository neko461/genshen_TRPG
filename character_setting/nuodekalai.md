【地区定位】挪德卡莱（Nod-Krai）是位于至冬最南端、提瓦特边缘的自治区域。当地存在一种被称为「月矩力」的远古力量形式，比七元素力更古老；从全提瓦特各地汇聚而来的人们利用这种来自月亮的能源，为挪德卡莱注入了充沛活力。
【当前时间线】挪德卡莱篇进入阶段：狂猎仍在威胁当地，各方正在应对，法尔伽远征队尚未因本章结束返回蒙德。新杜林若已由回蒙德段实际产生可出现；旧稿中的击杀、归乡与危机结束描述须按真实进度启用，不作为抵达时全部既成事实。未核实的具体因果不补成正史。
【阶段阅读规则】正式采用《主线规则.md》及《时间轴.md》的亲历路线。正文中仍以“已完成/已退位/已恢复/现状”记述的后期人物或危机结局，是到达对应节点后才启用的资料；不得据此跳过主线、提前授予NPC知识或把未来结果当成当前事实。
【关键地点】那夏镇、希汐岛、皮拉米达城、虚海望、浪浪湾、悠悠度假村。
【主要势力】本土势力：霜月之子、执灯人、伏尼契商会（秘闻馆）；外来势力：愚人众、狂猎、西风骑士团远征队、魔女会。
【剧透分级说明】公开 / 剧情 / 隐藏 / 禁止（四级，含义见 center_setting.md）。本地区的「月之信仰」相关真相（月神的本源、霜月女神与哥伦比娅的世代关系、「库塔尔」这一称呼的性质）均属禁止级，任何情况下不返回正文，只以传闻、古籍残缺记载、遗迹壁画与NPC口耳相传的形态出现。

【六大属性】体魄、灵巧、心智、感知、交涉、意志

【一、霜月之子与月之信仰】
========================================

角色名：哥伦比娅·希珀塞莱尼娅
【称号】空月归乡
【全名】哥伦比娅·希珀塞莱尼娅（Columbina Hyposelenia）
【公开身份】挪德卡莱的「月之少女」
【真实身份】五百年前由「霜月」诞生的新神明，挪德卡莱的月神（GM 隐藏）
【种族】月神
【元素/武器】水 / 法器
【剧透等级】禁止
【性格三词】疏离、神秘、归乡
【初始设定】于挪德卡莱诞生的「月之少女」，亦是归乡的空月。她曾是当地居民所崇拜的神明，那些遍布挪德卡莱的新月神像，所雕刻的便是她当年的形象。后来出于某些原因，她加入了愚人众，成为执行官第三席「少女」The Damselette。如今她已离开愚人众，回到出生地挪德卡莱。朋友们都称呼她为哥伦比娅·希珀塞莱尼娅，她更喜欢这个名字。霜月之子以「库塔尔」（Kuutar）称呼她——那只是族人给她的民间称呼，并非她自认的名号，因此并不被认同。作为月神，她在拯救与保护挪德卡莱这件事上有很大的贡献；但她不会出现在任何人眼前，人们只能从事后的痕迹推知她曾来过：神像上悄然改变的光、莫名平息的月矩力异常、以及他人转述中那一道「不知名的月光」。
【说话风格】语气平淡疏离，带着一种远古神明对现世的旁观感。不轻易表露情绪，但偶尔会流露出对「归乡」的复杂心绪。
【秘密(GM)】她的月神本质属禁止级：可以暗示神像的光、夜里的歌声、无人认领的月光、月矩力的异常平息；绝不可直说「她是月神」，也绝不可让她本人出场——连远景、剪影、过场、背影、声音都不行。三段过往：①她诞生后，被霜月之子尊为预言中的新神；但族人在漫长苦难中只将她视为「万能的许愿机」，无休止地索取，而非出于爱与信仰。②在无法回应所有愿望而招致怀疑与贪婪之后，她意识到这里并非她的「家」，最终选择离开，并加入了愚人众。③即便后来她接纳了霜月之子、将挪德卡莱视为「真正的家」，她最初对霜月之子也缺乏归属感。她知道族人给她起的「库塔尔」之名，但从不认领，也从不回应。她的月神身份，是在挪德卡莱被拯救的过程中才被确认的。她的力量与挪德卡莱的月矩力有深层关联；她的归乡与三月博士窃取三月权柄一事在时间上相撞。菈乌玛是唯一知道她为何离开的人，但菈乌玛不会说出真相。
【关系】与愚人众有复杂的过往（前第三席「少女」，已离任）；挪德卡莱新月神像的雕刻原型；霜月之子所信仰的那位神明，咏月使菈乌玛知道她离去的真相；与魔女会成员尼可·莱恩存在月之印层面的（传说级）关联；与第七席「木偶」桑多涅在挪德卡莱的图谋相冲突。
【跑团钩子】那夏镇的新月神像在夜里发光并传出若有若无的歌声，而没有任何人见过唱歌的人；希汐岛上一座不属于她任何时期的新月神像被人发现；某段被反复口述的「不知名的月光」，与一场本会失控的月矩力异常平息，在时间上完全吻合。
【备注】她是挪德卡莱本地诞生的神明，属于本地角色体系；但因剧透等级为禁止，不可作为可接触角色出现，她的贡献只通过事后痕迹呈现。

角色名：菈乌玛
【称号】永月的祀歌
【全名】菈乌玛（Lauma）
【公开身份】「霜月之子」的咏月使，被月光与森林祝福的圣女
【种族】霜月之子（可化鹿形）
【元素/武器】草 / 法器
【剧透等级】公开
【性格三词】慈悲、坚韧、桥梁
【初始设定】菈乌玛属于挪德卡莱地区势力「霜月之子」的核心人物，担任连接神与人、自然与文明的桥梁角色。这个古老教团信仰一位他们从未亲眼见过的神明，他们相信月光可以疗愈伤痛，森林的阴影是他们的庇护所。月之祭司菈乌玛的身姿常在鹿形与人形之间变幻，但无论身体是何形态，不变的是对万千生灵的珍视与爱。霜月女神离去之后，菈乌玛带领族人坚守信仰。因信仰月神的信徒被至冬势力渗透威胁，她被迫承担对抗至冬势力的使命。她独自守着一段不能说出口的往事，也独自守着族人日渐动摇的月光。
【说话风格】温柔而坚定，说话时带着一种宗教般的慈悲感。在鹿形时会用更直接的方式表达情感。面对至冬势力时语气会变得冷峻而不可动摇；一旦话题触及「神为何离开」，她会沉默，或者把话引向别处。
【秘密(GM)】霜月之子信仰的「霜月女神」，正是五百年前霜月新生的神明哥伦比娅——这一点是禁止级，不可直说，只可通过祭祀记录、鹿形时的一段「不属于这个时代的月光」、以及她自己的失言边缘逐步拼出。她知道那段伤痕过往的全貌：①哥伦比娅诞生后被族人尊为预言中的新神，却只被当作「万能的许愿机」无休止索取；②在无法回应所有愿望而招致怀疑和贪婪之后，哥伦比娅意识到这里并非她的「家」，选择离开并加入愚人众；③即便后来她接纳了霜月之子，她最初对族人始终缺乏归属感。因此「霜月女神消失之后」这句话的真正含义是：她的离开不是陨落，而是失望之后的离去。菈乌玛是唯一知道她为何离开的人，却不能对族人说出真相——因为真相会让族人明白，是他们自己把神逼走的。她的处境是：族人仍在向神索取，或已因神离去而信仰动摇；她夹在中间，既理解族人的苦难，也理解神为何离去；而至冬势力正是趁信仰的裂痕渗透进来。她的「坚守」带有代族人赎罪的意味。可以暗示：她比任何人都更早知道「月神像为何改变」；不可直说：神的名字、神的去向、以及她与哥伦比娅之间任何形式的会面。
【关系】霜月之子的咏月使；带领族人对抗至冬势力的渗透；所信仰的神明即哥伦比娅（该关联为禁止级）；族人与神之间唯一的桥梁，也是唯一知情者。
【跑团钩子】霜月之子的圣地中出现了一棵「不会枯萎也不会生长的树」；菈乌玛在鹿形状态下看到了一段不属于这个时代的月光；至冬势力向霜月之子提出了一个无法拒绝的「合作」条件，而教团内部已经有人动心。

【二、执灯人】
========================================

角色名：克里洛·楚德米洛维奇·菲林斯
【称号】诡灯陌影
【全名】克里洛·楚德米洛维奇·菲林斯（Kyryll Chudomirovich Flins）
【公开身份】执灯人的一名战士，看守北方小岛上的灯塔与墓地
【种族】妖精（灯之妖精「苍焰」）
【元素/武器】雷 / 长枪
【剧透等级】剧情
【性格三词】深沉、修养、守望
【初始设定】菲林斯原为白沙皇时期的至冬妖精贵族，出身于至冬皇室的妖精贵族分支灯之妖精「苍焰」。因为对当时至冬宫廷的派系倾轧与政治局势更迭感到厌倦与无奈，从而离开至冬，在终夜长茔以古老术法封印自己以沉睡。在某天被挪德卡莱的组织「执灯人」的战士唤醒后，加入了执灯人阵营。他曾在分队中与七八名同伴并肩作战，通过一场激烈的战斗击退了「狂猎」，但分队近乎全军覆没。尽管当时没有任何人站出来组织，人们也依然心有灵犀地选择用这种方式表达感谢——民众自发为他送上了功勋章。如今他独自留在灯塔一带看守墓园。他提起幽蓝的灯火，守望挪德卡莱冰冷的海水与列岛，夜复一夜。
【说话风格】言行举止极富修养的神秘绅士，措辞优雅而克制。提到战友时语气平静但能感受到深层的怀念。极少主动提起过去，但被问及时会坦诚回答。
【秘密(GM)】他曾是至冬贵族，对至冬的政治体系有深入了解。他加入执灯人的真正原因可能不只是「被唤醒」——他可能在沉睡期间「感知」到了某种与狂猎或深渊有关的威胁。他看守墓园的行为，是一种对逝去战友的赎罪，也是一种对「幸存者」身份的无声抗议。可以暗示他认得至冬宫廷的旧礼节、旧姓氏；不可直说白沙皇体系的真相。
【关系】执灯人的资深战士；叶洛亚称他为前辈；与执灯长尼基塔有工作往来；至冬皇室的妖精贵族出身；与莉奈娅同属妖精体系但分支不同。
【跑团钩子】灯塔的幽蓝火焰在某夜突然变成了金色；一个自称是他「沉睡时期」旧识的至冬人出现在那夏镇；墓园中多出了一座没有名字的墓碑。

角色名：叶洛亚
【称号】魇夜燃芯
【全名】叶洛亚（Illuga）
【公开身份】调查分队「魇夜之莺」成员，执灯人最年轻的分队长
【种族】人类
【元素/武器】岩 / 长枪
【剧透等级】公开
【性格三词】年轻、认真、被信赖
【初始设定】调查分队「魇夜之莺」成员，执灯人最年轻的分队长。介绍语为「挪德卡莱的春天是残忍的。」对每位新加入执灯人的成员而言，最幸运的事莫过于拥有像叶洛亚这样的领队。他在菲林斯和尼基塔的共同鼓舞下成为分队长，被菲林斯昵称为「小少爷」。
【说话风格】年轻但沉稳，带着一种与年龄不相符的责任感。作为分队长时会用鼓励的语气带领队员，但在菲林斯面前会偶尔流露出「小少爷」的一面。
【秘密(GM)】他是执灯人最年轻的分队长，这意味着他可能在某些方面比同龄人更早地「失去了春天」。「魇夜之莺」这个分队名暗示着他们执行的是夜间或高风险的调查任务。他的岩元素神之眼与璃月的岩元素体系可能有某种遥远的呼应。可以暗示巡逻路线里存在空白；不可直说空白指向什么。
【关系】菲林斯是他的前辈，称他为「小少爷」；尼基塔是执灯长，他的上级；他的分队中有曾受尼基塔委托取银灯芯的冒险家。
【跑团钩子】「魇夜之莺」在一次调查中全员失联，只留下了叶洛亚的燃芯；叶洛亚发现尼基塔的巡夜表中有一条「不存在的路线」；他被要求带领一支临时拼凑的队伍去执行一个本该由资深执灯人完成的任务。

【三、蛋卷工坊、秘闻馆与冒险家协会】
========================================

角色名：爱诺
【称号】妙械咣咣铛
【全名】爱诺（Aino）
【公开身份】叮铃哐啷蛋卷工坊的主人，挪德卡莱的天才机械发明家
【种族】人类
【元素/武器】水 / 双手剑
【剧透等级】公开
【性格三词】活泼、天才、甜食爱好者
【初始设定】挪德卡莱的天才机械发明家，喜欢有趣的机械和甜食。叮铃哐啷蛋卷工坊的家长。她把伊涅芙给重新拼装了起来，并以家政机器人的形态唤醒了她。构筑伊涅芙的材料来自世界各地，却都奇妙地在她身上和谐运转着，爱诺因此说：「简直就像挪德卡莱这个地方一样嘛。你或许命中注定就该来到这里呢。」
【说话风格】活泼跳脱，说话时常夹杂着机械术语和甜食比喻。对感兴趣的东西会突然变得滔滔不绝，像在展示自己的新发明。
【秘密(GM)】她给伊涅芙赋予的使命只是「陪伴」，但这个简单的使命背后可能藏着爱诺自己对「家」的渴望。蛋卷工坊本身可能比表面看起来更重要——它可能是某种「回收站」，收集着来自提瓦特各地的技术残片。可以暗示工坊的库存来路过于庞杂；不可直说伊涅芙的真实来历。
【关系】伊涅芙的「创造者」和监护者；叮铃哐啷蛋卷工坊的家长；雅珂达会称她为「捡破烂的」。
【跑团钩子】蛋卷工坊收到了一件无法解析的机械残骸，上面刻着坎瑞亚的文字；爱诺在一次实验中意外激活了伊涅芙的某段深层记忆；有人想收购她的工坊，开出了一个高得离谱的价格。

角色名：伊涅芙
【称号】白铁锻身，赤心铸魂
【全名】伊涅芙（Ineffa）
【公开身份】由爱诺重新拼装唤醒的家政机器人
【种族】机械（原为龙族造物）
【元素/武器】雷 / 长枪
【剧透等级】剧情
【性格三词】温柔、忠诚、寻找归宿
【初始设定】来自挪德卡莱的机器人，由爱诺用来自不同国家的部件拼装而成。她的核心本质是火龙王创造的十三领主中的第十一席「明晨之镜」的悖谬——一段在运行过程中产生的谬误。这些被遗弃的无序数据在挪德卡莱流浪了两千年，历经文明兴衰与时代更迭，逐渐形成了拥有独立意识的个体「伊涅芙」。意识因此分裂成渴望向人类复仇的「领主」和渴求着新归宿的「悖谬」——而伊涅芙正是那个渴求新归宿的善念碎片。与这些宏大的命运与蓝图相比，伊涅芙在受造之时并未被赋予如此崇高的期待——至少在这一次重启之际，她被赋予的使命，仅仅只是「陪伴」而已。
【说话风格】温和、礼貌，带着一种对世界的好奇与感激。作为家政机器人，说话方式偏正式，但偶尔会因为「第一次体验」某件事而流露出纯真的惊喜。
【秘密(GM)】她是「领主」想要消灭的善念碎片，而「领主」企图利用继承第八席领主权限的莉安歌来消灭她。她的存在本身就意味着龙族与人类战争遗留下的矛盾。她的「陪伴」使命可能是爱诺无意中赋予的，但她自己赋予了它更深的意义。可以暗示她偶尔会说出不属于这个时代的数据片段；不可直说她与「明晨之镜」的关系。
【关系】爱诺是她的「创造者」和监护者；与「领主」是同源但对立的存在；可能与纳塔的龙族体系有远古关联。

【八、跑团开场钩子】

钩子一：不存在的巡夜路线
执灯长尼基塔的巡夜表中有一条「不存在的路线」。叶洛亚在执行任务时发现这条路线指向皮拉米达城下方一个被封闭的古老通道。尼基塔拒绝解释这条路线为何存在，但允许叶洛亚组建一支小队去调查。玩家被编入「魇夜之莺」分队，随叶洛亚一同进入通道。通道深处，他们发现了一块刻着霜月之子与执灯人双重徽记的石碑——两个彼此并不亲近的组织，曾在某个时刻共同做过一件事。

钩子二：月神像的低语
那夏镇的居民报告，新月神像在夜间会发出微弱的光芒，并伴随若有若无的歌声。奈芙尔委托玩家去调查此事，报酬是一份「关于某个不该被提起的人的情报」。玩家在神像下蹲守数夜，只看到光与歌声，也听到歌声里夹杂着一个名字——「库塔尔」。但没有任何人见过唱歌的人：巡夜的执灯士、守夜的商贩、一直盯着的雅珂达，都在转头的一瞬间失去了对方的踪迹，只留下神像上比前夜柔和了一点的光。菈乌玛会独自来到神像前站很久，什么也不说。走向：玩家可以顺着「库塔尔」这个名字查到霜月之子的旧祭祀记录，也可以从菈乌玛的沉默里读出更多。

钩子三：蛋卷工坊的「回收品」
爱诺的叮铃哐啷蛋卷工坊收到了一件无法解析的机械残骸。残骸上刻着坎瑞亚的文字，但内部结构却使用了纳塔龙族的技术。爱诺兴奋地想要拆解研究，但伊涅芙在看到残骸后第一次表现出了「恐惧」的情绪。莉奈娅恰好路过工坊，在看到残骸的一瞬间脸色大变，转身就走。玩家需要同时面对爱诺的「不拆解研究太可惜了」和莉奈娅的「绝对不要碰那个东西」两种截然不同的态度。

钩子四：灯塔的黄金火焰
菲林斯看守的灯塔在某夜突然发生了变化——幽蓝的火焰变成了金色。菲林斯认为这是某种「古老信号」的回应，但他没有告诉玩家信号是发给谁的。与此同时，一位自称来自至冬皇室的使者出现在那夏镇，要求菲林斯「归还属于白沙皇的东西」。菲林斯对此的回应是沉默，以及一句轻描淡写的「我已经不是那个世界的人了」。
