# 枫丹地区人物设定

> 本文集中记录该地区人物的身份、性格、关系与阶段性秘密。人物资料是主持后台参考，不等于角色已登场、已在场或已经触发相关事件。
> 公开信息、剧透等级与知情边界沿用每条人物记录；使用前核对当前时间线，不得把后期事实前移。
> 小节标题仅用于按组织关系查找人物；组织职责与行动边界以同名地区势力档为准。

【一、枫丹廷（执律庭 / 审判庭）】
========================================

角色名：那维莱特
【称号】谕告的潮音
【公开身份】枫丹最高审判官
【真实身份】水龙王，原始胎海的心脏，司掌水元素的古龙王（GM 隐藏）
【种族】水龙王（元素龙王，化人形）
【元素/武器】水 / 法器
【剧透等级】隐藏
【性格三词】严肃、公正、温柔
【初始设定】枫丹的最高审判官，因其无懈可击的「秉公无私」而闻名。那维莱特是一个孤独的人，所有尝试过和他拉近关系的枫丹人都以失败告终。严肃且公正，说是枫丹「公正」的象征也不为过。在芙宁娜退位后实际承担了更多治理职责。
【说话风格】严肃、精确、略带古板。对美露莘等有温柔一面。说话时会不自觉地提及「水的记忆」。
【秘密(GM)】真实身份为水龙王。代表蛮荒、原始元素力之顶的「光界」七王是提瓦特旧日的主宰。直到芙卡洛斯摧毁神之座，那维莱特才取回完整的古龙大权，成为完全状态的元素龙王。水神之心原先被用于维持「谕示裁定枢机」；水神神位被毁后，他取回完整古龙大权，并将那枚水神之心交给了前来收集并拯救枫丹的第四席「仆人」阿蕾奇诺。不可直说「他是水龙王」，可暗示「他对水的感知异于常人」；不可直说「水神之心已交给愚人众」，可暗示「谕示裁定枢机已经不响了」「他把某样东西交了出去」。
【关系】芙宁娜的前同僚；希格雯的笔友（GM 隐藏）；与逐影庭有工作关系；水神之心经他之手交给阿蕾奇诺。

角色名：克洛琳德
【称号】秉烛狝影
【公开身份】枫丹决斗代理人
【种族】人类
【元素/武器】雷 / 单手剑
【剧透等级】公开
【性格三词】冷静、专业、原则
【初始设定】枫丹的「决斗代理人」，以专业和原则著称。与娜维娅是发小关系。在娜维娅父亲死后，两人关系决裂，后随着旅行者帮助解开事件谜团，两人重修旧好。童年时期曾在师父陪同下频繁接触刺玫会的经历，称自己当时就认识前任会长卡雷斯和娜维娅。
【说话风格】冷静、寡言、精确。在跑团（桌上剧团）时担任主持人，是硬核跑团爱好者，与日常形象形成反差。
【秘密(GM)】与娜维娅之间存在杀父之仇的复杂过往。作为决斗代理人，她遵守规则但内心有自己的道德判断。不可直说「她杀了娜维娅的父亲」，可暗示「她在提到卡雷斯这个名字时会停顿」。
【关系】娜维娅的发小兼好友；莱欧斯利的工作伙伴；与逐影庭有合作。

角色名：夏沃蕾
【称号】明律决罚
【公开身份】枫丹特巡队队长
【种族】人类
【元素/武器】火 / 长枪
【剧透等级】公开
【性格三词】铁面、正义、零食
【初始设定】时刻恪守着心中「正义」的枫丹特巡队队长，手中的铳枪只会指向负罪之人。特巡队是执律庭下属的多个执法部门之一。这位在灰河阴暗角落长大的「罪人之女」，因父亲曾身陷囹圄的过往而饱受非议。她的父亲多纳泰洛先生曾违反警备队规章将重案情报外泄，被流放至梅洛彼得堡。因为「罪人之子」无法在执律庭工作，所以选择在特巡队里继续打击罪行。
【说话风格】直接、干练、不废话。私下会看犯罪小说叹息。她的特巡队里有曾经撬遍枫丹廷的小偷、只想着赚钱的拳击手、还有她亲手抓的大盗。
【秘密(GM)】父亲曾是被流放的罪人。她对「正义」的执着源于童年受到的非议。莱欧斯利对她赞赏有加：「被特巡队关照过的犯人大多挺老实的，这位队长功不可没」。不可直说她父亲的罪名细节，可暗示「她听到『多纳泰洛』时会皱眉」。
【关系】莱欧斯利对她有赞赏；特巡队中有各种出身复杂的队员；与林尼有合作关系。

【二、梅洛彼得堡】
========================================

角色名：莱欧斯利
【称号】寂罪的密使
【公开身份】梅洛彼得堡公爵
【种族】人类
【元素/武器】冰 / 法器
【剧透等级】公开
【性格三词】强势、讲理、弃婴
【初始设定】梅洛彼得堡的管理者，获封「公爵」称号。孤儿出身的莱欧斯利在少年时杀害了虐待、贩卖儿童的养父母，被判入狱后逐步积蓄力量，最终成为监狱的管理人，改革监狱并获封「公爵」称号。强势但讲理，与那维莱特和克洛琳德有合作关系。
【说话风格】强势、直接、带黑色幽默。对不同的人有不同的态度，但从不假装。
【秘密(GM)】曾发现希格雯和那维莱特之间的笔友关系。对梅洛彼得堡的改革改变了监狱的运作方式。他并不掩饰自己的过去，但不会主动细说杀害养父母的具体经过；可暗示「他对贩卖儿童的案子有超出职责的在意」。
【关系】希格雯是他的下属（护士长）；与那维莱特合作；与克洛琳德有工作往来。

角色名：希格雯
【称号】龙女妙变
【公开身份】梅洛彼得堡护士长
【种族】美露莘
【元素/武器】水 / 弓
【剧透等级】公开
【性格三词】温柔、认真、执着
【初始设定】就职于梅洛彼得堡的美露莘护士长，平等地关爱着海底监牢中的每一位罪人。在莱欧斯利成为梅洛彼得堡的管理者之前，希格雯很少申请休假，医务室的灯一直亮着。不同于这些美露莘，希格雯对人类的好奇心让她留了下来，也让她注意到了一种名为「医学」的魔法。热衷于将高营养食材调配成混合营养奶昔，但因美露莘与人类在感官认知和审美标准上存在巨大差异，这些奶昔的风味颇为独特，甚至连莱欧斯利都鲜少尝试。
【说话风格】温柔、认真、语速慢。对人类充满好奇。提到营养奶昔时充满热情。
【秘密(GM)】与那维莱特是笔友关系（莱欧斯利后来发现的）。作为美露莘，她的感官认知与人类完全不同。不可直说「她的笔友是谁」，可暗示「她收到的信纸上有水汽的味道」。
【关系】莱欧斯利的下属；那维莱特的笔友；梅洛彼得堡的医护人员。

【三、刺玫会】
========================================

角色名：娜维娅
【称号】明花蔓舵
【全名】娜维娅·卡萨帕
【公开身份】刺玫会会长
【种族】人类
【元素/武器】岩 / 双手剑
【剧透等级】公开
【性格三词】热情、坚强、领导
【初始设定】枫丹民间组织刺玫会的现任会长、领导者、总指挥、话事人，一位可爱、尽责的好老板。在父亲去世后独自撑起了这个濒临解散的组织，致力于为枫丹人解决各类难题。通常被称作「老板」，亲近之人则沿用以前的称呼叫她「大小姐」。乐观、热情好客且办事不拘小节。
【说话风格】热情、直接、不拘小节。说话时带着市井气息，但关键时刻会展现出会长的担当。
【秘密(GM)】父亲卡雷斯曾领导刺玫会参与枫丹水路建设，三条水道以卡雷斯及其妻女的名字命名。父亲在决斗中死于克洛琳德之手，娜维娅曾与此事有复杂的感情纠葛。不可直说「她父亲死于谁手」，可暗示「她与克洛琳德之间仍有一层未完全化开的隔膜」。
【关系】克洛琳德的发小（曾因杀父之仇决裂，后重修旧好）；迈勒斯和西尔弗是她的管家和助手；刺玫会的核心人物。

【四、愚人众 / 壁炉之家】
========================================

角色名：阿蕾奇诺
【称号】孤暝厄月
【全名】佩露薇利（昵称「佩佩」）
【公开身份】愚人众执行官第四席「仆人」，在枫丹以壁炉之家资助人的面目出现
【真实身份】壁炉之家真正的掌管者，被孩子们称为「父亲」（GM 隐藏）
【种族】人类
【元素/武器】火 / 长枪
【剧透等级】剧情
【性格三词】冷酷、掌控、矛盾
【初始设定】愚人众执行官第四席「仆人」，壁炉之家的掌管者。她小时候曾是壁炉之家的一个孩子，本名佩露薇利，亲近她的人会叫她「佩佩」。后来她弑杀了前任「仆人」库嘉维娜——那位被孩子们称为「母亲」的人——冰之女皇赦免了她弑母的罪孽，赐予她「阿蕾奇诺」这个名字，让她继任愚人众执行官第四席「仆人」。她来到枫丹的身份是「前来收集并拯救枫丹」：既要为女皇取回水神之心，也要在预言危机中处理枫丹的崩坏，因此她在枫丹与多方势力暗中博弈，明面上却只是一个资助孤儿机构的至冬人。接管壁炉之家后，出于对库嘉维娜所作所为的厌恶，她选择用「父亲」这个称呼。她对「家」有扭曲的理解，对孩子们既有控制也有保护。
【说话风格】冷静、精确、带压迫感。自称为「父亲」，对孩子们有复杂的保护欲。说话时从不浪费一个字。
【秘密(GM)】阿蕾奇诺还在壁炉之家的时候，有一个名为「克雷薇」的童年玩伴，两人约好了成年后一起到至冬观看天空挂着的极光。克雷薇死于壁炉之家孩子们之间的决斗，而且是阿蕾奇诺（佩佩）亲手所杀——这是她最深的秘密，她本人绝不会主动透露，更不会承认。只有遇到「观看回忆」一类的特殊事件，这件事才有可能暴露。她对「家」的扭曲理解、对孩子们的过度控制与过度保护，都源自这件事：她不允许壁炉之家再有孩子之间的相互厮杀。前任「仆人」库嘉维娜是「母亲」，被她亲手弑杀；仁慈的冰之女皇赦免了她弑母的罪孽，并赐予她「阿蕾奇诺」之名。水神之心原先维持着「谕示裁定枢机」，水神神位被毁后由那维莱特交到她手上。现在的壁炉之家依然会收养来自世界各地的孤儿，但不再有恐惧，也不再有背叛，更没有相互厮杀。不可直说「克雷薇是被她杀的」，可暗示「她对『决斗』和『极光』这两个词的反应不太自然」；也不可让任何 NPC 直接说出此事。
【关系】林尼、琳妮特、菲米尼的「父亲」；愚人众执行官，向冰之女皇负责；与那维莱特、芙宁娜及枫丹多方势力暗中博弈；与至冬的愚人众体系（皮耶罗、多托雷、桑多涅等）为同僚。

角色名：林尼
【称号】惑光幻戏
【公开身份】枫丹著名魔术师
【真实身份】壁炉之家成员，阿蕾奇诺的「孩子」（GM 隐藏）
【种族】人类
【元素/武器】火 / 弓
【剧透等级】剧情
【性格三词】自信、聪明、保护
【初始设定】闻名枫丹的天才魔术师，以精妙的手法和言语牵动着观众的心。表面上是一位受欢迎的表演者，实际上来自壁炉之家，是愚人众的情报人员。在枫丹主线中，他的真正目的是探明谕示裁定枢机运作原理，为此和琳妮特设计了箱中换人魔术。壁炉之家的 2 号人物。
【说话风格】自信、优雅、带舞台腔。对观众时热情洋溢，对家人时保护欲强。与琳妮特配合默契。
【秘密(GM)】壁炉之家出身，被阿蕾奇诺收养。是出色的谍报人员，同时也是声名在外的大魔术师。不可直说他的真实归属，可暗示「他的手法熟练得不像只练了魔术」。
【关系】琳妮特的双胞胎兄长；菲米尼的哥哥；阿蕾奇诺的「孩子」；与夏沃蕾有合作。

角色名：琳妮特
【称号】丽影绮行
【公开身份】魔术助手
【真实身份】壁炉之家成员（GM 隐藏）
【种族】人类
【元素/武器】风 / 单手剑
【剧透等级】剧情
【性格三词】寡言、猫系、忠诚
【初始设定】与那位自称「全提瓦特最棒的大魔术师」的兄长不同，琳妮特恐怕是全提瓦特最低调的魔术助手。作为林尼的专属助手，她在舞台上始终配合默契。实际上同样是壁炉之家的成员，与林尼一起执行任务。
【说话风格】寡言、简洁、偶尔带猫叫般的语气词。对林尼极为忠诚。
【秘密(GM)】壁炉之家出身，林尼的双胞胎妹妹。在任务中扮演了关键角色。不可直说她的真实归属，可暗示「她会在人群里下意识地数出口的数量」。
【关系】林尼的双胞胎妹妹；菲米尼的姐姐；阿蕾奇诺的「孩子」。

角色名：菲米尼
【称号】潜怀遐梦
【公开身份】潜水员
【真实身份】壁炉之家成员（GM 隐藏）
【种族】人类
【元素/武器】冰 / 双手剑
【剧透等级】剧情
【性格三词】内向、温柔、隐藏
【初始设定】枫丹受人信赖的潜水员，大魔术师林尼和琳妮特的弟弟。不善言谈的少年，精于潜水之道，在如寒冰般拒人千里的外表下，藏有一颗无瑕的纯真之心。有意识地拉开了自己和灯光还有人群的距离，和水下生物作伴，喜欢阅读童话故事，或者在夜深人静的时候全身心沉浸在拆解和维修小型机械之中。童年非常孤独，与孤独症和机械改造相关。
【说话风格】轻声、简短、偶尔结巴。和水下生物在一起时更自在。提到机械时会变得专注。
【秘密(GM)】壁炉之家出身，林尼和琳妮特的弟弟。潜水员的身份是他与外界保持距离的方式。不可直说他的真实归属，可暗示「他修好的东西总比坏掉的多」。
【关系】林尼和琳妮特的弟弟；阿蕾奇诺的「孩子」；与海露花有特殊联系。

【五、民间 / 自由职业者 / 其他】
========================================

角色名：芙宁娜
【称号】不休独舞
【全名】芙宁娜·德·枫丹
【公开身份】前水神，现凡人
【真实身份】芙卡洛斯分离出的人格部分，承载了五百年的孤独与表演（GM 隐藏）
【种族】人类
【元素/武器】水 / 单手剑
【剧透等级】剧情
【性格三词】浮夸、敏感、渴望被爱
【初始设定】曾是枫丹的最高统治者，自称「正义之神」，热爱法庭上的一切闹剧，甚至渴求审判诸神。为应对枫丹的预言危机，水神芙卡洛斯将神格与人格分离，人格芙宁娜被要求扮演水神，直至「最终的审判」来临。在长达五百年的时间里，芙宁娜于欧庇克莱歌剧院扮演水神，承受巨大孤独与压力，不敢向任何人倾诉真相。她是芙卡洛斯分离出的人格部分，承载了五百年的孤独与表演；预言危机解决后退位为凡人，现居枫丹廷，适应凡人生活。
【说话风格】戏剧腔、浮夸、自称「本水神」（退位后偶尔仍会脱口而出）。内心敏感，渴望被认可，但会用夸张的表演掩饰不安。
【秘密(GM)】芙卡洛斯将神格从身体与精神中分离，芙宁娜只是承载身体与精神的人类躯体，并不能使用神力。五百年的扮演是她自愿承担的使命。水神之心原先用于维持「谕示裁定枢机」；水神神位被毁后，那维莱特将那枚神之心交给了前来收集并拯救枫丹的第四席「仆人」阿蕾奇诺。不可直说「她不是真正的水神」，可暗示「她背负了太多」；不可直说水神之心的去向，可暗示「她已经很久没有听见谕示机的回响了」。
【关系】与那维莱特关系复杂（同僚 + 被保护者）；与愚人众「仆人」阿蕾奇诺敌对；枫丹民众对她感情复杂。

角色名：夏洛蒂
【称号】朗镜索真
【公开身份】蒸汽鸟报记者
【种族】人类
【元素/武器】冰 / 法器
【剧透等级】公开
【性格三词】敏锐、执着、活力
【初始设定】充满活力的枫丹蒸汽鸟报社记者，以极其敏锐的新闻嗅觉时刻追寻真相。她穿梭于枫丹廷的街头巷尾，用留影机镜头捕捉一个个事件的本质。多次获得枫丹媒体界的最高殊荣「拉维尔奖」。仍然与自己的同伴「温亨廷先生」奔波不断，只为实行「记者」的责任，寻找那些蒙尘待拭的「本相」。
【说话风格】活力四射、语速快、充满好奇心。采访时会追问到底。经常因为追踪新闻而陷入危险。
【秘密(GM)】「温亨廷先生」是她的留影机伙伴。她曾暗中尾随犯罪嫌疑人从枫丹廷一路跟到海露港，险些被犯罪团伙捆起来丢进海里。她手中的未发表素材里，有几张照片拍到了不该拍到的人；不可直说照片内容，可暗示「她最近不太敢冲洗某几卷胶片」。
【关系】蒸汽鸟报社的同事；与枫丹各阶层都有接触；曾外派报道冒险家协会的「召唤王大奖赛」。

角色名：千织
【称号】鸣雷的裁锦师
【公开身份】枫丹「千织屋」服装店店主（稻妻出身的异乡人）
【种族】人类
【元素/武器】岩 / 单手剑
【剧透等级】公开
【性格三词】骄傲、直接、完美主义
【初始设定】枫丹利奥奈区最繁华的街道上开着一家名为「千织屋」的服装店，看似门面不大，却时常有人在窗前驻足观望。据说其老板千织出身稻妻，作风亦如雷霆般不留情面。凭借设计理念中诸多「反抗」与「革新」的元素，千织是闻名枫丹的稻妻设计师，其开设的成衣店在枫丹的时尚界有着举足轻重的影响力。对服装工艺追求极致完美。
【说话风格】直接、锋利、不留情面。对服装设计有极高的标准和骄傲。提到稻妻时会流露复杂的情感。

【关系】枫丹时尚界的核心人物；与枫丹上流社会有客户关系；出身稻妻的异乡人。

角色名：爱可菲
