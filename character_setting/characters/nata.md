# 纳塔地区人物设定

> 本文集中记录该地区人物的身份、性格、关系与阶段性秘密。人物资料是主持后台参考，不等于角色已登场、已在场或已经触发相关事件。
> 公开信息、剧透等级与知情边界沿用每条人物记录；使用前核对当前时间线，不得把后期事实前移。
> 小节标题仅用于按组织关系查找人物；组织职责与行动边界以同名地区势力档为准。

【一、纳塔·六英雄】
========================================

角色名：玛薇卡
【称号】焚曜千阳
【全名】玛薇卡（Mavuika）
【公开身份】纳塔火之神，纳塔领袖
【种族】人类（火神）
【元素/武器】火 / 双手剑
【剧透等级】剧情
【性格三词】豪迈、领袖、牺牲
【初始设定】纳塔的火之神，备受敬重的领袖。五百年前，前任火神为对抗深渊以提前死去为代价，于五百年后复活，玛薇卡便是这位回归的火神。对抗深渊是一场漫长的旅途，记忆与爱是她前行的动力。胜利之路由无数英雄共同铸就，而她自认为只是其中的代行者。她的古名为「基扬戈兹」，意为「领袖」——这是**历代火神继承的职阶性传承**，而非某一位火神的个人古名。
【说话风格】沉稳有力，语速不快但每句都带着重量。不使用华丽辞藻，但言语间有强烈的使命感和对同伴的信任。
【秘密(GM)】五百年前自我献祭、提前死去以在五百年后复活的真相。与队长卡皮塔诺之间有复杂的关系——队长曾替她投入圣火，代替她赴死，她对此怀有深层的感激与愧疚。此外，她在纳塔段之后的「世界树事件」中出借了**火神之心**，此后火神之心下落不明——此时尚未发生。可暗示：她背负着「本应由自己承担却由他人代付的代价」；不可直说：具体的代付者姓名与经过、以及火神之心的去向。
【关系】她计划中要觉醒的对象即**六英雄**（六部族各一人，见第七节）；六英雄是她的战友与代行者；队长卡皮塔诺是亦敌亦友的存在；「初代火神」希巴拉克是火神职阶的前代传承者（禁止级，仅在深层背景中）。
【备注】火神之心目前仍在玛薇卡手中；至冬段开始时，六枚神之心已入冰之女皇之手，唯有火神之心下落不明（见timeline.md 链 A 第 7 项、链 B）。


角色名：基尼奇
【称号】回火之狩
【全名】基尼奇（Kinich）
【公开身份】悬木人（维茨特兰）的猎龙人，六英雄之一
【种族】人类
【元素/武器】草 / 双手剑
【剧透等级】公开
【性格三词】现实、功利、可靠
【初始设定】「维茨特兰」的猎龙人，与自称「圣龙」的库胡勒阿乔同行。他自幼于山林间磨砺技艺，成为制服野兽与恶龙的行家。他承接各类委托，坚信「万事万物皆有代价」，现实功利的作风曾让他在部族中备受争议。惯于独行的他，如今身边也多了信任的伙伴。他的古名为「马力卜」，意为「回火」。
【说话风格】简短直接，带着一种「先谈报酬再谈感情」的务实感。提到阿乔时会流露出无奈，但不会承认自己在意这个搭档。
【秘密(GM)】与阿乔的契约关系中藏着代价的秘密。他「现实功利」的外表下，是在用报酬标准来衡量「保护珍贵之物」需要付出什么。可暗示：契约本身有代价、他清楚代价的存在；不可直说：代价的具体内容与阿乔的真实身份。
【关系】库胡勒阿乔是他的搭档；悬木人部族的猎龙人；六英雄之一（悬木人的代表）。


角色名：卡齐娜
【称号】斑金矿朴
【全名】卡齐娜（Kachina）
【公开身份】回声之子的年轻勇士，古名「乌沙博蒂」的继承者
【种族】人类
【元素/武器】岩 / 长柄武器
【剧透等级】公开
【性格三词】坚强、努力、纯真
【初始设定】回声之子的年轻勇士，受赐古名「乌沙博蒂」，意为「坚强」。过往的屡次战败让她难过不已，但她仍会擦干眼泪，继续前行。如今的她已经从巡礼中凯旋，得到**英雄之名（广义的英雄，并非六英雄之一）**，但她更加清楚那些失误和眼泪的意义。
【说话风格】语气认真但偶尔会透出紧张。说到战斗和训练时变得坚定，被夸奖时会不好意思。
【秘密(GM)】她在「巡夜者战争」中曾死于夜神之国，后被玛拉妮等人救回。这段经历让她对「生死」有了比同龄人更深刻的理解。可暗示：她对死亡有超出年龄的熟悉感；不可直说：她曾死过一次、以及是谁把她带回来的。
【关系】玛拉妮是她的挚友；回声之子的勇士；古名「乌沙博蒂」的继承者（**并非六英雄之一，但同属广义的「英雄」**）；与同为回声之子的希诺宁是同部族的前后辈——回声之子在六英雄中的代表是希诺宁，卡齐娜虽继承古名却不在六英雄之列。


角色名：玛拉妮
【称号】哗啦啦逐浪客
【全名】玛拉妮（Mualani）
【公开身份】梅兹特利的领路人，水上用品商店「悠游豚豚」的经营者，六英雄之一
【种族】人类
【元素/武器】水 / 法器
【剧透等级】公开
【性格三词】活泼、热情、朋友
【初始设定】来自「梅兹特利」的活泼姑娘，纳塔知名向导，也是水上用品商店「悠游豚豚」的经营者。作为人群里最耀眼的存在，她的笑声和欢呼声能瞬间点燃周围每一个人的热情。对于她来说，世界上分成两种人：一种是已经认识的朋友，另一种则是还没相遇的朋友。她的古名为「沃摩延」，意为「团结」。
【说话风格】轻快、热情，称呼所有人都是「朋友」。谈到正事时会突然变得认真可靠。
【秘密(GM)】她曾潜入夜神之国救出卡齐娜，这段经历让她对「朋友」的定义有了更深的重量。可暗示：她对夜神之国并不陌生、对「带朋友回来」有执念；不可直说：那次潜入的具体经过与卡齐娜曾死亡的事实。
【关系】卡齐娜是她的挚友；六英雄之一（流泉之众的代表）；「悠游豚豚」水上用品商店的经营者。


角色名：希诺宁
【称号】焮火铸魂
【全名】希诺宁（Xilonen）
【公开身份】回声之子的铸造师，六英雄之一
【种族】人类
【元素/武器】岩 / 单手剑
【剧透等级】公开
【性格三词】冷静、务实、匠人
【初始设定】回声之子部族的铸造师，纳塔最顶尖的锻造大师。人们因她高超的技艺慕名而来。在六英雄中负责装备与技术支持，对「古名」有深刻的理解。她的古名为「巴莱卡」，意为「祝福」。她的前辈是同属回声之子的**前铸名师特拉佐莉**——一位继承了古名「翁杜古」（亲情）的匠人，在希诺宁的传说任务中有重要戏份（特拉佐莉为非实机角色，不另设角色卡）。
【说话风格】平静、精确，像在描述一件刚完成的武器。不会寒暄，但会认真回答专业问题。
【秘密(GM)】她铸造的不只是武器——她曾为六英雄打造过与「古名」相配的器物。她对古名的理解远超一个铸造师应有的程度，其中一部分认知来自前辈特拉佐莉的传授。可暗示：她经手的器物「知道主人是谁」、她对古名的了解不合常理；不可直说：她为六英雄分别打造了什么。
【关系】六英雄之一（回声之子的代表）；回声之子部族；与同部族的卡齐娜是同族前后辈（卡齐娜是古名继承者，但不在六英雄之列）；前铸名师特拉佐莉（古名「翁杜古」）是她的前辈。


角色名：恰斯卡
【称号】裂羽
【全名】恰斯卡（Chasca）
【公开身份】花羽会（特拉洛坎）的调停人，六英雄之一
【种族】人类（与龙一同长大）
【元素/武器】风 / 弓
【剧透等级】公开
【性格三词】洒脱、野性、调停
【初始设定】「特拉洛坎」的调停人，以强大的实力和洒脱的个性而闻名。她与绒翼龙一同长大，继承了龙的野性与战斗直觉，又被「特拉洛坎」部族收养，记住了人与人之间的羁绊和温暖。出现在争斗的中心，以各种方式调解矛盾。她的古名为「武卡」，意为「超越」。
【说话风格】随意、带点野性，说话不绕弯子。调解矛盾时语气会变得沉稳，带着一种让人不自觉安静下来的力量。
【秘密(GM)】她在绒翼龙群中长大的经历让她对人类社会的「规则」始终保持着一种微妙的距离感。她的「调停」也是在调解自己内心「龙性」与「人性」之间的冲突。可暗示：她在人类聚落中始终有一点「不在其中」的气质；不可直说：她对自己归属的怀疑有多深。
【关系】六英雄之一（花羽会的代表）；花羽会部族；与绒翼龙有深厚羁绊。


角色名：欧洛伦
【称号】深黯的迷途
【全名】欧洛伦（Ororon）
【公开身份】烟谜主（米克特兰）的独居者，六英雄之一
【种族】人类
【元素/武器】雷 / 弓
【剧透等级】公开
【性格三词】费解、细心、天赋
【初始设定】在奇人云集的「米克特兰」部族，也显得相当与众不同的年轻人。平日在野外过着独居生活，说话方式略显费解，行动逻辑也不时超出常理。细心而耐心的他在照料动植物方面天赋异禀。
【说话风格】说话方式费解，经常用比喻和跳跃的逻辑。对动植物说话时反而比对人更流畅。
【秘密(GM)】他曾在夜神之国中做出了关键的选择，觉醒古名「庇迪」（意为「奉献」）的过程「更为刻骨铭心」。可暗示：他提到夜神之国时用词与旁人不同、对「奉献」一词有私人的理解；不可直说：他当年在夜神之国究竟选择了什么。
【关系】六英雄之一（烟谜主的代表）；烟谜主（米克特兰）部族；与动植物有特殊的交流方式；茜特菈莉同属烟谜主，是他所在部族的大萨满。


角色名：茜特菈莉
【称号】白星黑曜、黑曜石奶奶
【全名】茜特菈莉（Citlali）
【公开身份】烟谜主（米克特兰）的大萨满
【种族】人类
【元素/武器】冰 / 法器
【剧透等级】剧情
【性格三词】强大、神秘、狠角色
【初始设定】「烟谜主」的大萨满，名震纳塔的「黑曜石奶奶」。是绝对不可以招惹的狠角色。在烟谜主部族中地位超然，掌握着纳塔最古老的萨满知识。她的力量源于对古老萨满秘术的精通，**与古名无关**。
【说话风格】语气不紧不慢，但每句话都带着不容置疑的分量。习惯用「孩子」称呼年轻人。
【秘密(GM)】她**不持有古名**。她的力量来自对古老萨满秘术的精通。作为**研究者**，她对「古名」体系的理解可能触及夜神之国的底层规则——这只是研究者的深刻认知，**不是持有者的联系**。可暗示：她谈论古名时像一个解读者而非使用者、她保存着远超自身所需的古名记录；不可直说：她「与夜神之国联系极深」之类的持有者表述。
【关系】烟谜主部族的精神领袖；欧洛伦同属烟谜主（欧洛伦是六英雄，她不是）；对古名体系具备研究者的权威；阿伊祖（五百年前烟谜主首领）的部分知识可能由她继承。


角色名：伊安珊
【称号】熔火之心
【全名】伊安珊（Iansan）
【公开身份】沃陆之邦健身俱乐部的总教练，六英雄之一
【种族】人类
【元素/武器】火 / 长柄武器
【剧透等级】公开
【性格三词】热情、严格、营养
【初始设定】「沃陆之邦」健身俱乐部的总教练、闻名纳塔的营养师，同时也是「归火圣夜巡礼优胜者培训班」的创建者。她的古名是「力量」，而健身本质上就是一种通过自身努力获得力量的过程。
【说话风格】充满活力，说话像在给学员喊口号。训练时严格到令人害怕。提到营养搭配会突然变得非常专业。
【秘密(GM)】她的「力量」古名不是天赋赐予的，而是通过极端的努力和自律获得的。她对「力量来自天赋还是努力」有着超越健身层面的执念。可暗示：她从不谈自己「被选中」的那一刻；不可直说：她的古名曾在何时几乎失败。
【关系】六英雄之一（沃陆之邦的代表）；沃陆之邦部族；她的培训班培养了许多纳塔勇士。

【二、纳塔·其他勇士与龙伙伴】
========================================

角色名：瓦雷莎
【称号】山岚之守
【全名】瓦雷莎（Varesa）
【公开身份】特特奥坎的战士，果园经营者
【种族】人类
【元素/武器】雷 / 法器
【剧透等级】公开
【性格三词】温和、田园、反差
【初始设定】「特特奥坎」的战士，经营着一家果园，过着田园牧歌式的淳朴生活。平日性格温和悠哉，战斗的时候会戴上面具，变得情绪高涨，将魔物毫不留情地全数击退。
【说话风格】平日温和、慢悠悠的，像个普通的果园主。戴上战斗面具后语气完全改变，变得高亢、激昂，充满战意。
【秘密(GM)】她的「面具」不是古名器物，也**不算深渊造物的残留**——那其实就是一件玩具（或纪念物），与古名体系无关。它在战斗中充当的是她的**寄托/道具**，起到「开关」的作用：戴上它，她就会转入另一种情绪状态。但**她本人对「戴上它就会变成另一个自己」这一现象也说不清**。可暗示：她回避谈论面具是从哪来的、她对「戴上面具后的自己」既熟悉又陌生；不可直说：把面具解释成古名器物、深渊造物或任何超自然力量的产物。
【关系】特特奥坎部族；经营果园；与六英雄体系没有直接关系。


角色名：阿瓜拉
【称号】无（幼龙伙伴）
【全名】阿瓜拉（Aguara）
【公开身份】嵴锋龙的幼龙，玩家的龙伙伴
【种族】龙
【元素/武器】未知 / 无
【剧透等级】公开
【性格三词】幼小、好奇、陪伴
【初始设定】嵴锋龙的幼龙。在漫长的时光中，它都沉睡在未能孵化的壳中不愿醒来，直到你和你的龙伙伴将它从过往的遗迹中找到，向蛋壳呼唤它的名字。孵化出的小龙一直跟随着你，陪伴你，将与你一同成长。
【说话风格】无法用人类语言交流，通过叫声、动作和情绪传达。幼小但充满了对世界的探索欲。
【秘密(GM)】它「不愿醒来」的原因可能与五百年前的某次事件有关。它的蛋壳所在的遗迹，可能保存着纳塔更古老的历史。可暗示：蛋壳的纹样比其他龙蛋更古老、它对某些废墟有本能的抗拒；不可直说：它沉睡的真正理由。
【关系】玩家的龙伙伴；与纳塔的龙族体系有深层关联。


角色名：咔库库
【称号】无（龙医生/翻译）
【全名】咔库库（Kakuku）
【公开身份】绒翼龙的幼龙，伊法的助手，龙医生
【种族】龙
【元素/武器】未知 / 无
【剧透等级】公开
【性格三词】学舌、好奇、哥们
【初始设定】绒翼龙的幼龙，是伊法的助手，也是龙医生，负责和龙沟通，担当翻译。据称对人类的语言颇有了解，喜欢学伊法说话。无论如何，多和它聊聊天，它会把你当成好「哥们」的。
【说话风格】喜欢学人说话，用词常带模仿痕迹。自称「哥们」，语气轻松随意。
【秘密(GM)】它「翻译」的不只是龙的语言——它可能能听懂夜神之国的某种「声音」。可暗示：它偶尔会对空无一物的地方「翻译」、它复述的句子比它能理解的更复杂；不可直说：那种「声音」来自谁。
【关系】伊法的助手；绒翼龙；与阿瓜拉可能同属幼龙伙伴体系。

【四、在纳塔活动的非纳塔籍关键人物】
========================================

※ 以下角色并非纳塔本地人，但在纳塔剧情中扮演重要角色。他们属于外来势力，不能作为纳塔本地 NPC 随意遇到，应在剧情推进到相关节点时正式登场。

角色名：卡皮塔诺
【称号】愚人众执行官第一席「队长」
【全名】瑟雷恩（Thráin）
【公开身份】愚人众执行官第一席「队长」
【真实身份】坎瑞亚「天柱骑士」，本名瑟雷恩（GM 隐藏）
【种族】人类（坎瑞亚人）
【元素/武器】冰 / 单手剑（邪眼）
【剧透等级】隐藏
【性格三词】沉重、牺牲、使命
【初始设定】愚人众执行官第一席「队长」（注意：他是**第一席**「队长」；愚人众**统括官**是「丑角」皮耶罗，两人**不是同一人**）。他曾是坎瑞亚的「天柱骑士」，本名瑟雷恩，心脏经坎瑞亚技术改造，能将地脉中蕴含的记忆与灵魂转化为知识。五百年前坎瑞亚灾变时，他遇到了来自纳塔的桑哈杰；此后在纳塔与纳塔人并肩作战，与烟谜主部族首领阿伊祖结下深厚友谊。五百年后，他坐在**位于奥奇坎纳塔的王座**上，成为夜神之国永续的凭依。
【说话风格】低沉、克制，话不多但每句都带着五百年的重量。提及「代价」和「牺牲」时语气平静得令人不安。
【秘密(GM)】身负死之执政若娜瓦降下的**不死诅咒**，以不死之身承载了无数纳塔和坎瑞亚战士的灵魂。五百年前坎瑞亚灾变时期，纳塔地脉受损、深渊入侵，死之执政若娜瓦曾与**初代火神希巴拉克**达成约定：**借用死之执政的力量来稳固地脉，必须以「死亡」作为偿还**。然而**所有坎瑞亚人都被降下不死诅咒**，因此卡皮塔诺无法以「死亡」偿还。在纳塔剧情中，他与死之执政进行交易，向若娜瓦提出了一个**无法拒绝的选项**——**选项一**：解除他的不死诅咒，让他赴死（履行约定）；**选项二**：接受他与夜神之国融合，让夜神获得永生。**若娜瓦作为天理的下属，无权解除天理降下的诅咒，因此只能被迫接受后者。**最终他牺牲，永远坐在「位于奥奇坎纳塔的王座」上（**奥奇坎纳塔是地名**），成为夜神之国永续的凭依，**无法进行任何行动**。
【GM 边界】**交易内容正常不应知晓**——玩家与 NPC 均不可得知细节。若娜瓦本身为「禁止」级，与之绑定的交易内容同样不应出场。可暗示：他「做出了选择」、他现在「处于永恒的静默中」、他付了某个代价；不可直说：交易的双方是谁、两个选项的具体内容、约定的原文与由来。
【关系】玛薇卡是亦敌亦友的存在；若娜瓦（死之执政）是他的诅咒来源与交易对象（禁止级，不可出场）；阿伊祖是五百年前的战友（烟谜主首领，临终前向他透露「某物拥有重构地脉的能力」）；桑哈杰是坎瑞亚灾变时他遇到的纳塔人；古瑟雷德是他最信任的副官（已牺牲）；「丑角」皮耶罗是愚人众统括官，与他同属女皇核心圈层但**并非同一人**；冰之女皇在他牺牲后为他保留了第一席的席位。
【备注】此角色为至冬／坎瑞亚背景，在纳塔剧情中属于外来关键人物，不可作为纳塔本地 NPC 随意遇到。他坐困于奥奇坎纳塔的王座、**无法行动**，因此不存在「他主动留下的印记正在运作」这一可能；任何相关线索都应以「王座作为地脉节点」或「他人在奥奇坎纳塔附近观察到的异象」的形式出现。


NPC 名：希巴拉克（禁止级·历史人物）
【身份】初代火神
【所属】纳塔（远古／五百年前层）
【出现地点】不可登场。仅可以「古籍残卷」「遗迹壁画」「萨满口述中残缺的句子」等间接形态出现
【设定】**初代火神**，火神职阶的起点。（玛薇卡的古名「基扬戈兹」是历代火神继承的职阶性传承，这一传承自他而始。）五百年前坎瑞亚灾变时期，纳塔地脉受损、深渊入侵，他与死之执政若娜瓦达成约定：**借用死之执政的力量来稳固地脉，必须以「死亡」作为偿还**。这一约定是后来「队长的交易」的前置条件。
【GM 边界】依格式规范第七节，「禁止」级条目**任何情况下都不返回正文**，只返回可用的间接表述。可暗示：夜神之国最古老的壁画上有一个「向死借力的人」、古籍中反复出现「借来的死亡必须偿还」一类的残缺句子；不可直说：他与若娜瓦约定的全文、他与若娜瓦的关系细节、以及他作为火神的具体事迹。
【剧透等级】禁止
