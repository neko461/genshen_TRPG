# 稻妻地区势力设定

> 本文回答“当地有哪些组织、它们承担什么职责、当前处于什么阶段”。人物个体资料见相邻目录的 `../characters/daoqi.md`。
> 具体行动以当前场景和已记录事实为准。组织设定不能自动生成阴谋、委托、敌对关系或玩家必须加入的立场。

## 地区定位与当前阶段

【地区定位】雷元素的国度，信奉「永恒」。稻妻幕府为最高统治机构，雷电将军为最高主宰；三奉行（社奉行、天领奉行、勘定奉行）分管政务、治安与财政。海祇岛为独立势力，信奉珊瑚宫。进入本章时锁国令与眼狩令仍在实施。
【当前时间线】稻妻篇进入阶段：锁国令与眼狩令仍在施行并影响民众，奉行与反抗力量的冲突未解决。雷电将军公开治理，雷电影的一心净土及其真相仍受知情限制；雷神之心移交、废令和三奉行改革须在对应事件后发生。神樱大祓不默认完成。
【阶段阅读规则】正式采用《mainline-rules.md》及《timeline.md》的亲历路线。正文中仍以“已完成/已退位/已恢复/现状”记述的后期人物或危机结局，是到达对应节点后才启用的资料；不得据此跳过主线、提前授予NPC知识或把未来结果当成当前事实。
【关键地点】稻妻城、天守阁、鸣神大社、海祇岛、珊瑚宫、渊下宫、神里屋敷、长野原烟花店、八重堂、离岛、鹤观。
【主要势力】稻妻幕府（社奉行、天领奉行、勘定奉行）、鸣神大社、海祇岛·珊瑚宫、终末番、荒泷派、狛荷屋、长野原烟花店、愚人众（在稻妻转入地下活动）。

## 势力职责

| 势力 | 现有设定中的职责与边界 |
|---|---|
| **稻妻幕府与三奉行** | 幕府为最高统治机构；社奉行、天领奉行、勘定奉行分别影响政务、治安与财政。进入本章时锁国令与眼狩令仍在施行。 |
| **鸣神大社** | 承担鸣神信仰及神社事务；八重神子也与八重堂和稻妻重要事件相连。 |
| **海祇岛·珊瑚宫** | 具有独立立场与信仰体系；珊瑚宫心海领导当地，海祇军与幕府存在现实冲突。 |
| **终末番** | 与社奉行相关的隐秘行动网络，行动范围和知情程度须按剧情逐步揭露。 |
| **荒泷派** | 以荒泷一斗为中心的民间团体；能提供地方关系和生活线，不自动承担国家冲突的主导权。 |
| **狛荷屋、长野原烟花店** | 分别连接稻妻物流与烟花行业，是角色和城市日常的入口。 |
| **愚人众** | 在稻妻转入地下活动；若其参与眼狩令或其他事件，应由具体证据建立关联。 |

## 主持使用边界

- 先按玩家当下所在位置、已建立关系和组织公开职责判断谁能合理介入；不能因为名单里存在某势力，就让它突然出现。
- 组织可以彼此合作、冲突或保持距离，但具体关系须有当前阶段和已知事实支持。
- 当异常原因未明时，优先核对地区历史、地脉/元素、深渊与天理相关背景；普通人祸须有具体证据和可信动机。
- 地区主线优先级与推进要求见 `../hooks/daoqi.md` 及 `../../docs/rules/mainline-rules.md`。
