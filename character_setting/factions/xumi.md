# 须弥地区势力设定

> 本文回答“当地有哪些组织、它们承担什么职责、当前处于什么阶段”。人物个体资料见相邻目录的 `../characters/xumi.md`。
> 具体行动以当前场景和已记录事实为准。组织设定不能自动生成阴谋、委托、敌对关系或玩家必须加入的立场。

## 地区定位与当前阶段

【地区定位】草元素的国度，雨林与沙漠并存。教令院是学术管理机构，六大学派中以知论派和因论派最为核心；进入本章时虚空系统仍被用于知识与日常事务，关闭须待对应剧情。
【当前时间线】须弥篇进入阶段：花神诞祭循环、教令院控制与造神冲突尚未解决。纳西妲尚未因本章事件获得公开全面执政，虚空仍在运作；散兵不是已改造的流浪者。神之心交换、切片处置和世界树记忆事件均须在相应阶段后处理。
【阶段阅读规则】正式采用《mainline-rules.md》及《timeline.md》的亲历路线。正文中仍以“已完成/已退位/已恢复/现状”记述的后期人物或危机结局，是到达对应节点后才启用的资料；不得据此跳过主线、提前授予NPC知识或把未来结果当成当前事实。
【关键地点】须弥城、教令院、净善宫、化城郭、道成林、阿如村、赤王陵、缄默之殿、桓那兰那、奥摩斯港。
【主要势力】教令院（六大学派）、三十人团、镀金旅团、缄默之殿、祖拜尔剧场、兰那罗、愚人众（须弥残党）。

## 势力职责

| 势力 | 现有设定中的职责与边界 |
|---|---|
| **教令院与六大学派** | 掌握学术管理和虚空系统；当前花神诞祭循环、贤者控制与造神计划仍是核心冲突。 |
| **三十人团** | 承担须弥城及相关区域的治安与雇佣事务。 |
| **镀金旅团** | 沙漠地区的重要民间武装与雇佣团体；内部立场不一，不应一律写成敌人。 |
| **缄默之殿** | 与沙漠历史及当地遗迹事务相关，具体参与以阶段资料为准。 |
| **祖拜尔剧场** | 须弥城的表演与公共文化场所，妮露在此活动。 |
| **兰那罗** | 雨林中的非人族群，与森林、记忆和当地生态有关；需按角色认知边界呈现。 |
| **愚人众残党** | 须弥的外部行动者之一；不得把造神危机简化成普通愚人众委托。 |

## 主持使用边界

- 先按玩家当下所在位置、已建立关系和组织公开职责判断谁能合理介入；不能因为名单里存在某势力，就让它突然出现。
- 组织可以彼此合作、冲突或保持距离，但具体关系须有当前阶段和已知事实支持。
- 当异常原因未明时，优先核对地区历史、地脉/元素、深渊与天理相关背景；普通人祸须有具体证据和可信动机。
- 地区主线优先级与推进要求见 `../hooks/xumi.md` 及 `../../docs/rules/mainline-rules.md`。
