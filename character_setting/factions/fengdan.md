# 枫丹地区势力设定

> 本文回答“当地有哪些组织、它们承担什么职责、当前处于什么阶段”。人物个体资料见相邻目录的 `../characters/fengdan.md`。
> 具体行动以当前场景和已记录事实为准。组织设定不能自动生成阴谋、委托、敌对关系或玩家必须加入的立场。

## 地区定位与当前阶段

【地区定位】水元素的国度，以审判与律法闻名。最高审判官与水神构成「法权」与「神权」的双重象征，枫丹廷是政治中心，梅洛彼得堡是海底监狱。
【当前时间线】枫丹篇进入阶段：预言危机尚未解决，芙宁娜仍以水神身份公开活动，那维莱特承担最高审判官职责。神位处置、完整权能恢复与水神之心移交不能提前生效。水仙十字是重要可选长支线，按玩家参与逐步展开，不预设已完成。
【阶段阅读规则】正式采用《mainline-rules.md》及《timeline.md》的亲历路线。正文中仍以“已完成/已退位/已恢复/现状”记述的后期人物或危机结局，是到达对应节点后才启用的资料；不得据此跳过主线、提前授予NPC知识或把未来结果当成当前事实。
【关键地点】枫丹廷、梅洛彼得堡、白淞镇、露景泉、欧庇克莱歌剧院、灰河、海露港、伊黎耶岛、枫丹动能工程科学研究院、巡轨船线路
【主要势力】枫丹廷（执律庭 / 审判庭 / 逐影庭 / 特巡队）、梅洛彼得堡、刺玫会、愚人众（壁炉之家）、蒸汽鸟报、枫丹科学院

## 势力职责

| 势力 | 现有设定中的职责与边界 |
|---|---|
| **枫丹廷各机构** | 执律庭、审判庭、逐影庭与特巡队承担执法、审判和调查等职责；按制度与各自权限行动。 |
| **梅洛彼得堡** | 海底监狱及其自治秩序由莱欧斯利主持，希格雯负责医疗照护。 |
| **刺玫会** | 娜维娅领导的地方组织，连接白淞镇、案件调查与民间救援。 |
| **愚人众·壁炉之家** | 阿蕾奇诺及其相关成员在枫丹活动；角色的个人立场与组织任务不应简单等同。 |
| **蒸汽鸟报** | 新闻机构，可提供公开信息和调查入口；报道不自动等同于核实结论。 |
| **枫丹科学院** | 承担工程与科学研究；涉及禁忌研究或灾害时须有明确证据和阶段依据。 |

## 主持使用边界

- 先按玩家当下所在位置、已建立关系和组织公开职责判断谁能合理介入；不能因为名单里存在某势力，就让它突然出现。
- 组织可以彼此合作、冲突或保持距离，但具体关系须有当前阶段和已知事实支持。
- 当异常原因未明时，优先核对地区历史、地脉/元素、深渊与天理相关背景；普通人祸须有具体证据和可信动机。
- 地区主线优先级与推进要求见 `../hooks/fengdan.md` 及 `../../docs/rules/mainline-rules.md`。
