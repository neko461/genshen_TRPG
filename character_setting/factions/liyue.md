# 璃月地区势力设定

> 本文回答“当地有哪些组织、它们承担什么职责、当前处于什么阶段”。人物个体资料见相邻目录的 `../characters/liyue.md`。
> 具体行动以当前场景和已记录事实为准。组织设定不能自动生成阴谋、委托、敌对关系或玩家必须加入的立场。

## 地区定位与当前阶段

【地区定位】岩元素的国度，以「契约」为理念，提瓦特商贸中心；进入本章时帝君退位与魔神危机尚未收束，七星负责日常政务；「人治时代」是相应事件后的发展。
【当前时间线】璃月篇进入阶段：请仙典仪及帝君“遇害”事件尚未收束，魔神危机未解决。七星处理现实政务，仙人与人类的关系通过本章发展；钟离以往生堂客卿身份出现，真实身份与神之心契约不公开。不能把“退位一年后”和后续海灯节人物状态提前生效。
【阶段阅读规则】正式采用《mainline-rules.md》及《timeline.md》的亲历路线。正文中仍以“已完成/已退位/已恢复/现状”记述的后期人物或危机结局，是到达对应节点后才启用的资料；不得据此跳过主线、提前授予NPC知识或把未来结果当成当前事实。
【关键地点】璃月港、玉京台、绯云坡、吃虎岩、往生堂、不卜庐、群玉阁、月海亭、绝云间、奥藏山、层岩巨渊、轻策庄、翘英庄、沉玉谷、遗珑埠。
【主要势力】璃月七星、总务司与千岩军、三眼五显仙人、往生堂、不卜庐、南十字船队、飞云商会、云翰社、剑匣镖局、沉玉谷手工艺工会、北国银行（至冬据点）。

## 势力职责

| 势力 | 现有设定中的职责与边界 |
|---|---|
| **璃月七星** | 负责港口及璃月的日常政务。请仙典仪与帝君遇害异变发生后，七星需要处理调查、城市秩序和魔神危机。 |
| **总务司与千岩军** | 承担政务执行、治安、防务与救援；按职责反应，不把所有决定都交给玩家。 |
| **三眼五显仙人** | 与璃月有古老契约，在魔神危机中涉及守护、协作及人仙关系；不能一开始就替七星或玩家解决危机。 |
| **往生堂** | 负责葬仪事务；胡桃主持堂务，客卿钟离以凡人身份公开活动。 |
| **不卜庐** | 璃月的医疗与药材机构，白术、七七在此活动。 |
| **南十字船队** | 由北斗统领，提供海上交通与船员人脉。 |
| **飞云商会、云翰社、剑匣镖局、沉玉谷手工艺工会** | 分别连接商贸、戏曲、护送和沉玉谷地方事务；适合作为人物关系或支线入口。 |
| **北国银行** | 愚人众在璃月的据点，牵涉商贸和外交压力；不得仅凭其存在就把普通商业纠纷写成阴谋。 |

## 主持使用边界

- 先按玩家当下所在位置、已建立关系和组织公开职责判断谁能合理介入；不能因为名单里存在某势力，就让它突然出现。
- 组织可以彼此合作、冲突或保持距离，但具体关系须有当前阶段和已知事实支持。
- 当异常原因未明时，优先核对地区历史、地脉/元素、深渊与天理相关背景；普通人祸须有具体证据和可信动机。
- 地区主线优先级与推进要求见 `../hooks/liyue.md` 及 `../../docs/rules/mainline-rules.md`。
